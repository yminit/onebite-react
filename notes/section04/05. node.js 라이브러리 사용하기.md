# Section 4 - 5. Node.js 라이브러리 사용하기

**1. 라이브러리란?**

라이브러리는 개발에 필요한 기능을 **미리 만들어 놓은 코드 모음**이다.

필요한 기능을 직접 만들지 않고 설치해서 사용할 수 있다.

---

**2. npm으로 패키지 설치하기**

Node.js에서는 npm을 이용해 외부 패키지를 설치한다.

```bash id="npmlib01"
npm i randomcolor
```

`npm i`는 `npm install`의 줄임말이다.

```bash id="npmlib02"
npm install randomcolor
```

---

**3. 패키지를 설치하면 생기는 것**

패키지를 설치하면 다음 항목들이 관련된다.

```text id="npmlib03"
package.json
→ 필요한 패키지 정보

package-lock.json
→ 실제 설치 버전과 의존성 정보

node_modules
→ 실제 설치된 패키지 파일
```

`package.json`에서는 주로 `dependencies`에서 확인할 수 있다.

---

**4. 패키지 다시 설치하기**

`package.json`에 의존성 정보가 있다면 다음 명령어로 필요한 패키지를 다시 설치할 수 있다.

```bash id="npmlib04"
npm i
```

주로 `node_modules`가 없는 상태에서 프로젝트 의존성을 다시 설치할 때 사용한다.

---

**5. 설치한 라이브러리 사용하기**

npm으로 설치한 패키지는 패키지 이름으로 불러온다.

```javascript id="npmlib05"
import randomColor from "randomcolor";

const color = randomColor();

console.log(color);
```

직접 만든 모듈과 비교하면 다음과 같다.

```javascript id="npmlib06"
// 직접 만든 모듈
import { add } from "./math.js";

// 설치한 외부 패키지
import randomColor from "randomcolor";
```

```text id="npmlib07"
직접 만든 모듈
→ 파일 경로 사용

외부 패키지
→ 패키지 이름 사용
```

---

**6. 핵심 정리**

* 라이브러리는 미리 만들어진 기능을 가져와 사용하는 것이다.
* `npm i 패키지명`으로 외부 패키지를 설치한다.
* `dependencies`에는 프로젝트가 사용하는 패키지가 기록된다.
* `node_modules`에는 실제 패키지 파일이 설치된다.
* `package-lock.json`은 설치된 버전과 의존성 정보를 더 구체적으로 기록한다.
* `npm i`로 프로젝트에 필요한 패키지를 다시 설치할 수 있다.
* 직접 만든 모듈은 경로로, 외부 패키지는 패키지 이름으로 `import`한다.
