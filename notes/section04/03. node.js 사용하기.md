# Section 4 - 3. Node.js 사용하기

**1. 프로젝트와 패키지**

프로젝트는 **특정 목적을 가진 프로그램 단위**이다.

Node.js에서는 보통 하나의 프로젝트를 하나의 **패키지(Package)**로 관리한다.

패키지 정보는 `package.json`에 저장된다.

---

**2. Node.js 패키지 만들기**

프로젝트 폴더에서 다음 명령어를 실행한다.

```bash id="node401"
npm init
```

설정을 완료하면 `package.json` 파일이 생성된다.

```text id="node402"
프로젝트 폴더
├─ src/
│  └─ index.js
└─ package.json
```

---

**3. package.json**

`package.json`은 프로젝트의 설정과 패키지 정보를 관리하는 파일이다.

주요 정보는 다음과 같다.

```text id="node403"
name
→ 패키지 이름

version
→ 버전

scripts
→ 실행 명령어

dependencies
→ 설치한 패키지 정보
```

현재 단계에서는 특히 `scripts`를 알아두면 된다.

---

**4. JavaScript 실행하기**

`src/index.js`:

```javascript id="node404"
console.log("hello nodejs");
```

Node.js로 직접 실행한다.

```bash id="node405"
node src/index.js
```

실행 결과:

```text id="node406"
hello nodejs
```

---

**5. npm scripts**

자주 사용하는 명령어는 `package.json`의 `scripts`에 등록할 수 있다.

```json id="node407"
{
  "scripts": {
    "start": "node src/index.js"
  }
}
```

이후 다음처럼 실행한다.

```bash id="node408"
npm run start
```

실제 실행 흐름은 다음과 같다.

```text id="node409"
npm run start
→ package.json의 start 확인
→ node src/index.js 실행
```

---

**6. 핵심 정리**

* Node.js 프로젝트는 보통 하나의 패키지로 관리한다.
* `npm init`으로 패키지를 생성한다.
* `package.json`은 프로젝트의 설정과 정보를 관리한다.
* `node 파일경로`로 JavaScript 파일을 직접 실행할 수 있다.
* `scripts`에 명령어를 등록하면 `npm run 이름`으로 실행할 수 있다.
* npm scripts는 길거나 자주 사용하는 명령어를 간단하게 관리할 때 사용한다.
