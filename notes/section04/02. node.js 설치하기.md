# Section 4 - 2. Node.js 설치하기

**1. Node.js 설치**

Node.js 공식 사이트에서 자신의 운영체제에 맞는 설치 파일을 다운로드한다.

처음 설치할 때는 보통 **LTS(Long Term Support)** 버전을 사용한다.

```text
LTS
→ 장기간 안정적으로 지원되는 버전
```

설치 과정은 특별한 이유가 없다면 기본 설정으로 진행하면 된다.

---

**2. Node.js 설치 확인**

터미널에서 다음 명령어를 실행한다.

```bash
node -v
```

정상적으로 설치되었다면 Node.js 버전이 출력된다.

```text
vXX.XX.X
```

---

**3. npm**

Node.js를 설치하면 일반적으로 `npm`도 함께 설치된다.

`npm`은 **Node Package Manager**의 약자로, JavaScript 개발에 필요한 패키지를 설치하고 관리하는 도구이다.

React 같은 프론트엔드 개발에서도 자주 사용한다.

설치 여부는 다음 명령어로 확인한다.

```bash
npm -v
```

---

**4. 설치 확인 흐름**

```text
Node.js 설치
→ node -v
→ Node.js 버전 확인
→ npm -v
→ npm 버전 확인
```

두 명령어 모두 정상적으로 버전이 출력되면 사용할 준비가 된 것이다.

---

**5. 핵심 정리**

* Node.js는 공식 사이트에서 설치한다.
* 처음 설치할 때는 보통 LTS 버전을 사용한다.
* `node -v`로 Node.js 설치를 확인한다.
* `npm`은 패키지를 설치하고 관리하는 도구이다.
* `npm -v`로 npm 설치를 확인한다.
