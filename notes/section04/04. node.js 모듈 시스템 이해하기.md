# Section 4 - 4. Node.js 모듈 시스템 이해하기

**1. 모듈이란?**

모듈은 기능을 **파일 단위로 분리한 것**이다.

```text
src/
├─ index.js
└─ math.js
```

예를 들어 `math.js`에는 계산 기능을 작성하고, `index.js`에서 불러와 사용할 수 있다.

모듈을 사용하면 파일별 역할을 구분하기 쉬워진다.

---

**2. 모듈 시스템**

모듈 시스템은 다른 파일에 있는 기능을 **내보내고 불러오는 방식**이다.

대표적으로 다음 두 가지가 있다.

```text
CommonJS
ES Module
```

---

**3. CommonJS**

CommonJS에서는 다음 문법을 사용한다.

```text
내보내기 → module.exports
불러오기 → require()
```

`math.js`

```javascript
function add(a, b) {
  return a + b;
}

function sub(a, b) {
  return a - b;
}

module.exports = {
  add,
  sub,
};
```

`index.js`

```javascript
const { add, sub } = require("./math");

console.log(add(1, 2));
console.log(sub(1, 2));
```

---

**4. ES Module**

ES Module은 JavaScript의 표준 모듈 시스템이다.

```text
내보내기 → export
불러오기 → import
```

Node.js에서 `.js` 파일에 ESM 문법을 사용하는 현재 실습에서는 `package.json`에 다음 설정을 추가한다.

```json
{
  "type": "module"
}
```

---

**5. Named Export**

여러 값을 이름으로 내보낼 때 사용한다.

```javascript
function add(a, b) {
  return a + b;
}

function sub(a, b) {
  return a - b;
}

export { add, sub };
```

불러올 때는 `{}`를 사용한다.

```javascript
import { add, sub } from "./math_esm.js";
```

---

**6. Default Export**

기본값 하나를 내보낼 때 사용한다.

```javascript
function multiply(a, b) {
  return a * b;
}

export default multiply;
```

불러올 때는 `{}`를 사용하지 않는다.

```javascript
import multiply from "./math_esm.js";
```

Named Export와 함께 사용할 수도 있다.

```javascript
import multiply, { add, sub } from "./math_esm.js";
```

---

**7. CommonJS와 ES Module 비교**

```text
CommonJS
module.exports
require()

ES Module
export
import
```

현재 프론트엔드 학습에서는 특히 **ES Module의 `import` / `export` 사용법**을 잘 익혀두면 된다.

---

**8. 핵심 정리**

* 모듈은 기능을 파일 단위로 분리한 것이다.
* 모듈 시스템을 이용해 다른 파일의 기능을 내보내고 불러올 수 있다.
* CommonJS는 `module.exports`, `require()`를 사용한다.
* ES Module은 `export`, `import`를 사용한다.
* Named Export는 여러 값을 이름으로 내보낸다.
* Default Export는 기본값 하나를 내보낸다.
* Node.js에서 현재 실습처럼 `.js`를 ESM으로 사용할 때는 `"type": "module"`을 설정한다.
* 모듈을 사용하면 코드의 역할을 분리하고 관리하기 쉬워진다.
