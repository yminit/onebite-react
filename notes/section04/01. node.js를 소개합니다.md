# Section 4 - 1. Node.js를 소개합니다

**1. Node.js란?**

Node.js는 **브라우저 밖에서 JavaScript를 실행할 수 있게 해주는 JavaScript 런타임**이다.

```text id="njs01"
JavaScript 코드
→ Node.js
→ 실행
```

Node.js는 Chrome에서도 사용하는 **V8 JavaScript 엔진**을 기반으로 한다.

---

**2. 왜 Node.js가 필요한가?**

JavaScript는 원래 브라우저에서 실행되는 언어였다.

Node.js가 등장하면서 JavaScript를 브라우저 밖에서도 실행할 수 있게 되었다.

```text id="njs02"
기존
→ 브라우저에서 JavaScript 실행

Node.js
→ 브라우저 밖에서도 JavaScript 실행
```

---

**3. Node.js로 할 수 있는 것**

Node.js를 사용하면 다음과 같은 작업이 가능하다.

* 서버와 API 개발
* 파일 처리
* 개발 도구 실행
* 패키지 설치
* 개발 서버 실행
* 빌드

현대적인 프론트엔드 개발에서도 많이 사용한다.

```text id="njs03"
Node.js
→ React / Next.js 등의 개발 환경
→ 패키지 설치
→ 개발 서버
→ 빌드
```

React 자체가 Node.js에서만 실행되는 것은 아니다.

React로 만든 JavaScript는 최종적으로 브라우저에서도 실행되며, Node.js는 주로 **개발 과정**에서 사용된다.

---

**4. 브라우저와 Node.js 차이**

둘 다 JavaScript를 실행하지만 제공하는 기능이 다르다.

```text id="njs04"
브라우저
→ 웹 페이지 실행
→ DOM 사용 가능

Node.js
→ 브라우저 밖에서 JavaScript 실행
→ 서버, 파일 시스템 등의 기능 사용
```

예를 들어 `document`는 브라우저가 제공하는 기능이므로 일반적인 Node.js 환경에서는 사용할 수 없다.

---

**5. 핵심 정리**

* Node.js는 JavaScript 런타임이다.
* 브라우저 밖에서도 JavaScript를 실행할 수 있게 해준다.
* Chrome과 같은 V8 JavaScript 엔진을 기반으로 한다.
* 서버 개발뿐 아니라 프론트엔드 개발 도구 실행에도 사용한다.
* React, Next.js 개발 과정에서 패키지 설치, 개발 서버, 빌드 등에 Node.js가 사용된다.
* 브라우저와 Node.js는 JavaScript를 실행하지만 제공하는 기능은 다르다.
