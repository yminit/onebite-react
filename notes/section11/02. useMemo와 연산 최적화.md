# Section 11 - 2. useMemo와 연산 최적화

**1. useMemo란?**

`useMemo`는 **연산 결과를 기억해서 불필요한 재계산을 줄이는 Hook**이다.

```text
처음 계산
→ 결과 저장

의존성 변경 없음
→ 저장된 결과 재사용

의존성 변경
→ 다시 계산
```

---

**2. 기본 형태**

```jsx
const value = useMemo(() => {
  return 계산결과;
}, [의존성]);
```

의존성 배열의 값이 바뀌면 다시 계산하고, 바뀌지 않으면 이전 결과를 재사용한다.

---

**3. Todo 통계 계산**

현재 Todo List에서는 다음 값을 계산한다.

```text
totalCount
→ 전체 Todo 개수

doneCount
→ 완료된 Todo 개수

notDoneCount
→ 미완료 Todo 개수
```

```jsx
const { totalCount, doneCount, notDoneCount } = useMemo(() => {
  const totalCount = todos.length;

  const doneCount = todos.filter(
    (todo) => todo.isDone
  ).length;

  const notDoneCount = totalCount - doneCount;

  return {
    totalCount,
    doneCount,
    notDoneCount,
  };
}, [todos]);
```

---

**4. 왜 useMemo를 사용할까?**

`List`에는 검색어 State도 있다.

```jsx
const [search, setSearch] = useState("");
```

검색어가 변경되면 `List`가 리렌더링된다.

하지만 `todos`가 변하지 않았다면 Todo 통계는 다시 계산할 필요가 없다.

```text
search 변경
→ List 리렌더링
→ todos 변경 X
→ 이전 통계 결과 재사용
```

반대로 Todo가 추가·수정·삭제되면 `todos`가 변경되므로 통계를 다시 계산한다.

---

**5. [todos]의 의미**

```jsx
}, [todos]);
```

통계 계산이 `todos`에 의존한다는 의미이다.

```text
todos 변경
→ useMemo 다시 계산

todos 변경 없음
→ 이전 결과 재사용
```

---

**6. 렌더링 흐름**

```text
List 렌더링
→ Todo 통계 계산
→ 결과 저장

search 변경
→ List 리렌더링
→ todos 동일
→ 저장된 결과 재사용

todos 변경
→ useMemo 다시 계산
→ 새로운 결과 저장
```

---

**7. 계산 결과 사용**

`useMemo`가 반환한 값은 일반 값처럼 JSX에서 사용한다.

```jsx
<div>total: {totalCount}</div>
<div>done: {doneCount}</div>
<div>notDone: {notDoneCount}</div>
```

---

**8. useMemo를 사용할 때의 기준**

`useMemo`는 모든 계산에 사용하는 것이 아니다.

```text
단순하고 비용이 작은 계산
→ 굳이 useMemo 필요 없음

리렌더링마다 반복되고
계산 비용이 큰 작업
→ useMemo 고려
```

`useMemo` 자체에도 값을 비교하고 결과를 보관하는 비용이 있기 때문에 **필요한 곳에만 적용하는 것**이 중요하다.

---

**9. useMemo와 useCallback**

현재 단계에서는 다음처럼 구분하면 된다.

```text
useMemo
→ 계산된 값을 기억

useCallback
→ 함수 자체를 기억
```

이후 함수 재생성 최적화에서 `useCallback`을 사용한다.

---

**10. 핵심 정리**

* `useMemo`는 메모이제이션을 이용해 불필요한 연산을 줄인다.
* 기본 형태는 `useMemo(() => 계산, [의존성])`이다.
* 의존성이 변경되면 다시 계산한다.
* 의존성이 그대로면 이전 계산 결과를 재사용한다.
* 현재 예제에서는 `todos`가 바뀔 때만 Todo 통계를 다시 계산한다.
* `search`만 변경되면 기존 통계 결과를 재사용한다.
* 단순한 계산까지 무조건 `useMemo`로 감싸는 것은 좋지 않다.
* `useMemo`는 **연산 결과**, `useCallback`은 **함수**를 메모이제이션한다.
