# Section 12 - 2. Context 사용하기

**1. Context 생성하기**

먼저 `createContext()`로 Context 객체를 만든다.

```jsx
export const TodoContext = createContext();
```

현재 프로젝트에서는 다음 데이터를 공유한다.

```text
TodoContext
├─ todos
├─ onCreate
├─ onUpdate
└─ onDelete
```

---

**2. Provider로 데이터 공급하기**

`Provider`는 Context 데이터를 하위 컴포넌트에 공급한다.

```jsx
<TodoContext.Provider
  value={{
    todos,
    onCreate,
    onUpdate,
    onDelete,
  }}
>
  <Editor />
  <List />
</TodoContext.Provider>
```

```text
Provider
→ value로 데이터 공급
→ 내부 컴포넌트에서 사용
```

---

**3. useContext로 데이터 사용하기**

Context 값을 사용할 컴포넌트에서는 `useContext()`를 사용한다.

```jsx
const value = useContext(TodoContext);
```

필요한 값만 꺼낼 수도 있다.

```jsx
const { onCreate } = useContext(TodoContext);
```

---

**4. Editor에서 사용**

기존:

```text
App
↓ onCreate Props
Editor
```

Context 적용 후:

```jsx
const { onCreate } = useContext(TodoContext);
```

이제 `App`에서는 다음처럼 작성할 수 있다.

```jsx
<Editor />
```

```text
TodoContext
→ onCreate
→ Editor
```

---

**5. List에서 사용**

`List`는 전체 Todo 목록을 Context에서 가져온다.

```jsx
const { todos } = useContext(TodoContext);
```

기존:

```jsx
<List todos={todos} />
```

변경 후:

```jsx
<List />
```

```text
TodoContext
→ todos
→ List
→ 검색 및 목록 렌더링
```

---

**6. TodoItem에서 사용**

`TodoItem`은 수정과 삭제 함수를 가져온다.

```jsx
const { onUpdate, onDelete } = useContext(TodoContext);
```

따라서 `List`가 이 함수들을 중간에서 전달할 필요가 없다.

```jsx
<TodoItem
  key={todo.id}
  {...todo}
/>
```

```text
기존
App → List → TodoItem

Context 적용
TodoContext → TodoItem
```

Props Drilling이 줄어든다.

---

**7. Props와 Context 함께 사용하기**

Context를 사용한다고 Props가 없어지는 것은 아니다.

현재 `TodoItem`에서는 Todo 자체의 데이터는 Props로 전달한다.

```text
List
↓ Props
TodoItem

id
isDone
content
date
```

공통으로 필요한 함수는 Context에서 가져온다.

```text
TodoContext
↓
TodoItem

onUpdate
onDelete
```

즉, **Props와 Context는 상황에 따라 함께 사용한다.**

---

**8. 현재 전체 구조**

```text
App
│
├─ useReducer
│  └─ todos 관리
│
├─ onCreate
├─ onUpdate
├─ onDelete
│
└─ TodoContext.Provider
   │
   ├─ Editor
   │  └─ useContext → onCreate
   │
   └─ List
      ├─ useContext → todos
      │
      └─ TodoItem
         └─ useContext → onUpdate / onDelete
```

---

**9. 지금까지 사용한 기능 연결**

```text
useReducer
→ Todo State 변경 로직 관리

useCallback
→ onCreate / onUpdate / onDelete 함수 유지

Context
→ 데이터와 함수 공유

useContext
→ Context 값 사용
```

각 기능의 역할이 다르다.

---

**10. 핵심 정리**

* `createContext()`로 Context를 생성한다.
* `Provider`의 `value`에 공유할 데이터를 넣는다.
* Provider 내부 컴포넌트에서 Context 데이터를 사용할 수 있다.
* `useContext(Context)`로 필요한 데이터를 가져온다.
* `Editor`는 `onCreate`를 사용한다.
* `List`는 `todos`를 사용한다.
* `TodoItem`은 `onUpdate`, `onDelete`를 사용한다.
* Context를 이용하면 중간 컴포넌트가 Props를 전달만 하는 **Props Drilling을 줄일 수 있다.**
* Context와 Props는 서로 대체 관계가 아니라 필요에 따라 함께 사용할 수 있다.
* 핵심 흐름은 **`createContext → Provider로 공급 → useContext로 사용`**이다.
