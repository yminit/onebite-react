# Section 7 - 1. 프로젝트 소개 및 준비

**1. Counter App 프로젝트 생성**

Vite로 새로운 React 프로젝트를 만든다.

```bash
npm create vite@latest
```

설정은 다음과 같이 선택한다.

```text
Framework → React
Variant   → JavaScript
```

프로젝트 폴더로 이동한 뒤 패키지를 설치한다.

```bash
cd section7
npm i
```

---

**2. ESLint 설정**

이번 실습에서는 `eslint.config.js`를 다음 목적에 맞게 설정한다.

```text
dist
→ ESLint 검사 제외

.js / .jsx
→ ESLint 검사 대상

JavaScript 권장 규칙
React Hook 권장 규칙
Vite React Refresh 규칙
→ 적용
```

---

**3. 주요 ESLint 설정**

### a. dist 제외

```javascript
globalIgnores(["dist"]);
```

`dist`는 빌드 결과물이 들어가는 폴더이므로 ESLint 검사에서 제외한다.

### b. 검사할 파일 지정

```javascript
files: ["**/*.{js,jsx}"]
```

JavaScript와 JSX 파일에 ESLint 설정을 적용한다.

### c. 권장 규칙 적용

```javascript
extends: [
  js.configs.recommended,
  reactHooks.configs.flat.recommended,
  reactRefresh.configs.vite,
]
```

```text
js.configs.recommended
→ JavaScript 기본 권장 규칙

reactHooks.configs.flat.recommended
→ React Hook 관련 규칙

reactRefresh.configs.vite
→ Vite React Refresh 관련 규칙
```

---

**4. 브라우저와 JSX 설정**

브라우저 환경의 전역 객체를 ESLint가 인식하도록 설정한다.

```javascript
languageOptions: {
  globals: globals.browser,
}
```

JSX 문법도 인식하도록 설정한다.

```javascript
parserOptions: {
  ecmaFeatures: {
    jsx: true,
  },
}
```

---

**5. 실습에서 끄는 규칙**

```javascript
rules: {
  "no-unused-vars": "off",
  "react/prop-types": "off",
}
```

```text
no-unused-vars
→ 사용하지 않는 변수 검사 비활성화

react/prop-types
→ PropTypes 관련 검사 비활성화
```

이 설정들은 이전 Section에서 이미 다룬 내용이므로 역할만 기억하면 된다.

---

**6. 프로젝트 준비 흐름**

```text
npm create vite@latest
→ React 선택
→ JavaScript 선택
→ cd section7
→ npm i
→ eslint.config.js 설정
→ Counter App 구현 시작
```

---

**7. 핵심 정리**

* 이번 Section에서는 Counter App을 구현한다.
* Vite로 `React + JavaScript` 프로젝트를 만든다.
* `npm i`로 필요한 의존성을 설치한다.
* `eslint.config.js`에서 JavaScript, React Hook, Vite 관련 규칙을 설정한다.
* `dist`는 ESLint 검사에서 제외한다.
* `no-unused-vars`, `react/prop-types`는 이번 실습에서 비활성화한다.
* 초기 설정이 끝나면 Counter App 구현을 시작하면 된다.
