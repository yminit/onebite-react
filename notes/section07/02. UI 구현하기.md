# Section 7 - 2. UI 구현하기

**1. Counter App 구조**

이번 단계에서는 기능보다 **화면 구조를 먼저 구현**한다.

```text
App
├─ Viewer
└─ Controller
```

```text
App
→ 전체 화면 구성

Viewer
→ 현재 카운트 표시

Controller
→ 카운트 조작 버튼 표시
```

---

**2. App 컴포넌트**

`App`에서 `Viewer`와 `Controller`를 조합한다.

```jsx
import "./App.css";

import Viewer from "./components/Viewer";
import Controller from "./components/Controller";

function App() {
  return (
    <div className="App">
      <h1>Simple Counter</h1>

      <section>
        <Viewer />
      </section>

      <section>
        <Controller />
      </section>
    </div>
  );
}

export default App;
```

`App`이 부모이고 `Viewer`, `Controller`가 자식 컴포넌트이다.

---

**3. Viewer 컴포넌트**

`Viewer`는 현재 카운트를 보여준다.

```jsx
const Viewer = () => {
  return (
    <div>
      <div>현재 카운트 :</div>
      <h1>0</h1>
    </div>
  );
};

export default Viewer;
```

현재는 State를 연결하지 않았기 때문에 `0`을 직접 표시한다.

---

**4. Controller 컴포넌트**

`Controller`는 카운트를 변경할 버튼들을 보여준다.

```jsx
const Controller = () => {
  return (
    <div>
      <button>-1</button>
      <button>-10</button>
      <button>-100</button>
      <button>+100</button>
      <button>+10</button>
      <button>+1</button>
    </div>
  );
};

export default Controller;
```

현재는 이벤트를 연결하지 않았기 때문에 버튼을 눌러도 값은 변경되지 않는다.

---

**5. 기본 스타일**

```css
body {
  padding: 20px;
}

.App {
  margin: 0 auto;
  width: 400px;
}

.App > section {
  background-color: rgb(245, 245, 245);
  border: 1px solid rgb(240, 240, 240);
  border-radius: 5px;
  padding: 20px;
  margin-bottom: 10px;
}
```

핵심만 보면 다음과 같다.

```text
.App
→ 너비 400px
→ 가운데 정렬

.App > section
→ Viewer / Controller 영역 스타일
```

---

**6. 현재 프로젝트 구조**

```text
src/
├─ components/
│  ├─ Viewer.jsx
│  └─ Controller.jsx
├─ App.jsx
├─ App.css
└─ main.jsx
```

---

**7. 핵심 정리**

* 이번 단계는 Counter App의 UI 구조를 만드는 단계이다.
* `App`은 전체 화면을 조합한다.
* `Viewer`는 현재 카운트를 표시한다.
* `Controller`는 카운트 변경 버튼을 표시한다.
* 현재 카운트는 `0`으로 고정되어 있다.
* 버튼에는 아직 이벤트가 연결되지 않았다.
* 다음 단계에서 State와 이벤트를 연결해 실제 카운터 기능을 구현한다.
