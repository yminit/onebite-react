# Section 2 - 4. 변수와 상수

**1. 변수와 상수란?**

변수와 상수는 값을 저장하는 공간이다.

```javascript
let age = 27;
const birth = "1997.01.07";
```

* `let`: 값을 나중에 변경할 수 있음
* `const`: 선언 후 다시 할당할 수 없음

---

**2. 변수 `let`**

변수는 `let`으로 선언한다.

```javascript
let age = 27;

age = 30;
```

선언만 하고 값을 넣지 않으면 `undefined`가 된다.

```javascript
let name;

console.log(name); // undefined
```

같은 범위에서 같은 이름의 `let` 변수를 다시 선언할 수는 없다.

```javascript
let age = 27;

// 오류
let age = 30;
```

하지만 기존 변수의 값을 변경하는 것은 가능하다.

---

**3. 상수 `const`**

상수는 `const`로 선언하며 **선언과 동시에 값을 넣어야 한다.**

```javascript
const birth = "1997.01.07";
```

한 번 할당한 값을 다시 할당할 수 없다.

```javascript
const birth = "1997.01.07";

// 오류
birth = "2000.01.01";
```

---

**4. 변수 이름 규칙**

변수 이름은 다음 규칙을 지켜야 한다.

```text
가능
→ 영문자
→ 숫자
→ $
→ _

불가능
→ 숫자로 시작
→ 예약어 사용
→ 대부분의 특수문자 사용
```

예시:

```javascript
let userName;
let user1;
let $price;
let _name;
```

잘못된 예시:

```javascript
// let 2name;
// let user-name;
// let if;
```

---

**5. 변수 이름은 의미 있게 작성하기**

변수 이름만 보고 어떤 값인지 알 수 있도록 작성하는 것이 좋다.

```javascript
let salesCount = 10;
let refundCount = 2;
let totalCount = salesCount - refundCount;
```

다음처럼 의미가 불분명한 이름은 피한다.

```javascript
let a = 10;
let b = 2;
let c = a - b;
```

---

**6. 핵심 정리**

* `let`은 값을 변경할 수 있다.
* `const`는 선언 후 다시 할당할 수 없다.
* 값을 넣지 않은 `let` 변수는 `undefined`가 된다.
* 같은 범위에서 같은 이름의 `let`을 다시 선언할 수 없다.
* `const`는 선언과 동시에 초기화해야 한다.
* 변수 이름은 숫자로 시작할 수 없고 예약어를 사용할 수 없다.
* 변수 이름은 값의 의미를 알 수 있게 작성한다.
