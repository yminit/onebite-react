# Section 2 - 14. 스코프

**1. 스코프란?**

스코프는 **변수나 함수에 접근할 수 있는 범위**이다.

```javascript
function funcA() {
  let b = 2;

  console.log(b);
}
```

`b`는 `funcA` 내부에서만 사용할 수 있다.

---

**2. 전역 스코프**

함수나 블록 바깥에서 선언한 값은 여러 곳에서 접근할 수 있다.

```javascript
let a = 1;

function funcA() {
  console.log(a);
}

console.log(a);
```

`a`는 전역 변수이므로 함수 안과 밖에서 모두 사용할 수 있다.

---

**3. 지역 스코프**

특정 영역 안에서만 사용할 수 있는 범위이다.

### a. 함수 스코프

함수 내부에서 선언한 값은 함수 밖에서 사용할 수 없다.

```javascript
function funcA() {
  let b = 2;

  console.log(b);
}

// console.log(b); // 오류
```

### b. 블록 스코프

`let`, `const`는 `{}` 블록 안에서만 사용할 수 있다.

```javascript
if (true) {
  let c = 1;
  const d = 2;
}

// console.log(c); // 오류
// console.log(d); // 오류
```

조건문과 반복문에서도 동일하다.

---

**4. 스코프 접근 방향**

안쪽 스코프에서는 바깥쪽 값을 사용할 수 있다.

```javascript
let a = 1;

function funcA() {
  let b = 2;

  console.log(a);
  console.log(b);
}
```

반대로 바깥쪽에서는 안쪽 값을 사용할 수 없다.

```text
전역 스코프
└─ 함수 스코프
   └─ 블록 스코프
```

```text
안쪽 → 바깥쪽 접근 가능
바깥쪽 → 안쪽 접근 불가
```

---

**5. 핵심 정리**

* 스코프는 변수나 함수에 접근할 수 있는 범위이다.
* 전역 스코프의 값은 여러 영역에서 사용할 수 있다.
* 지역 스코프의 값은 선언된 영역 안에서만 사용할 수 있다.
* `let`, `const`는 블록 스코프를 가진다.
* 안쪽 스코프에서는 바깥쪽 값에 접근할 수 있다.
* 바깥쪽 스코프에서는 안쪽 값에 접근할 수 없다.
