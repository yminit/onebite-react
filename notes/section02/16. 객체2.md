# Section 2 - 16. 객체 2

**1. 상수 객체**

객체를 `const`로 선언하면 **변수 자체를 다른 값으로 다시 할당할 수는 없지만**, 객체 내부의 프로퍼티는 변경할 수 있다.

```javascript
const animal = {
  type: "고양이",
  name: "나비",
};
```

다음은 가능하다.

```javascript
animal.age = 2;
animal.name = "까망이";
delete animal.type;
```

하지만 새로운 객체를 다시 넣는 것은 불가능하다.

```javascript
// 오류
animal = {
  type: "강아지",
};
```

```text
const 객체

객체 자체 재할당
→ 불가능

프로퍼티 추가/수정/삭제
→ 가능
```

---

**2. 메서드란?**

객체의 프로퍼티 값이 함수라면 이를 **메서드**라고 한다.

```javascript
const person = {
  name: "이정환",

  sayHi() {
    console.log("hi");
  },
};
```

메서드는 객체가 수행하는 동작을 표현한다.

---

**3. 메서드 호출**

일반 함수처럼 `()`를 붙여 실행한다.

```javascript
person.sayHi();
```

대괄호 표기법도 사용할 수 있다.

```javascript
person["sayHi"]();
```

동적으로 메서드를 선택할 때도 사용할 수 있다.

```javascript
const methodName = "sayHi";

person[methodName]();
```

---

**4. 핵심 정리**

* `const` 객체는 다른 객체로 다시 할당할 수 없다.
* 객체 내부의 프로퍼티는 추가, 수정, 삭제할 수 있다.
* 메서드는 값이 함수인 객체 프로퍼티이다.
* 메서드는 보통 `메서드이름() {}` 형태로 작성한다.
* 메서드는 점 표기법이나 대괄호 표기법으로 호출할 수 있다.
