# Section 2 - 9. 조건문

**1. 조건문이란?**

조건문은 **조건에 따라 실행할 코드를 나누는 문법**이다.

대표적으로 `if`와 `switch`를 사용한다.

---

**2. if 조건문**

조건식이 `true`일 때 코드를 실행한다.

```javascript
let num = 10;

if (num >= 10) {
  console.log("10 이상");
}
```

여러 조건을 확인할 때는 `else if`, 모든 조건이 거짓일 때는 `else`를 사용한다.

```javascript
if (num >= 10) {
  console.log("10 이상");
} else if (num >= 5) {
  console.log("5 이상");
} else {
  console.log("5 미만");
}
```

조건은 **위에서부터 순서대로 확인**하며, 처음으로 참이 된 부분만 실행된다.

따라서 범위를 비교할 때는 더 구체적인 조건을 먼저 작성하는 것이 좋다.

---

**3. switch 조건문**

`switch`는 **하나의 값을 여러 경우와 비교할 때** 사용한다.

```javascript
let animal = "cat";

switch (animal) {
  case "cat":
    console.log("고양이");
    break;

  case "dog":
    console.log("강아지");
    break;

  default:
    console.log("알 수 없는 동물");
}
```

* `case`: 비교할 값
* `break`: 해당 `case` 실행 후 `switch` 종료
* `default`: 일치하는 `case`가 없을 때 실행

`break`가 없으면 아래 `case`도 계속 실행될 수 있다.

---

**4. if와 switch 차이**

```text
if
→ 범위 비교
→ 여러 조건 조합
→ 복잡한 조건

switch
→ 하나의 값을 여러 값과 비교
→ 특정 값에 따른 분기
```

예를 들면

```javascript
if (score >= 90) {
  // 범위 비교
}
```

```javascript
switch (menu) {
  case "save":
    // 특정 값 비교
    break;
}
```

처럼 구분해서 사용할 수 있다.

---

**5. 핵심 정리**

* 조건문은 조건에 따라 실행할 코드를 나눈다.
* `if`는 다양한 조건식을 처리할 때 사용한다.
* `else if`는 추가 조건, `else`는 나머지 경우를 처리한다.
* 조건은 위에서부터 순서대로 확인한다.
* `switch`는 하나의 값을 여러 경우와 비교할 때 적합하다.
* `case`는 비교 값, `break`는 종료, `default`는 기본 처리 역할을 한다.
