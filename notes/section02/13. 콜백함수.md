# Section 2 - 13. 콜백 함수

**1. 콜백 함수란?**

콜백 함수는 **다른 함수에 인수로 전달되는 함수**이다.

```javascript
function main(callback) {
  callback();
}

main(() => {
  console.log("sub");
});
```

여기서 화살표 함수가 콜백 함수이다.

---

**2. 콜백 함수 동작**

전달된 함수는 매개변수에 저장되고, 필요할 때 호출한다.

```text
함수 전달
  ↓
매개변수에 저장
  ↓
callback()
  ↓
전달된 함수 실행
```

예시:

```javascript
function main(callback) {
  console.log(1);
  callback();
  console.log("end");
}

main(() => {
  console.log("sub");
});
```

실행 결과:

```text
1
sub
end
```

---

**3. 콜백 함수 활용**

콜백을 사용하면 **공통 구조는 유지하고 실행할 동작만 바꿀 수 있다.**

```javascript
function repeat(count, callback) {
  for (let i = 1; i <= count; i++) {
    callback(i);
  }
}
```

사용할 때 원하는 동작을 전달한다.

```javascript
repeat(5, (i) => {
  console.log(i);
});

repeat(5, (i) => {
  console.log(i * 2);
});
```

```text
repeat
→ 반복 구조 담당

callback
→ 반복할 때 실행할 동작 담당
```

---

**4. 핵심 정리**

* 콜백 함수는 다른 함수에 인수로 전달되는 함수이다.
* 전달된 함수는 필요한 시점에 호출할 수 있다.
* 같은 함수에 다른 콜백을 전달해 동작을 바꿀 수 있다.
* 콜백을 사용하면 공통 로직과 실제 실행할 동작을 분리할 수 있다.
