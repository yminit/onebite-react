# Section 2 - 1. 안녕 자바스크립트

**1. JavaScript란?**

JavaScript는 **웹 페이지에 기능과 동작을 추가하는 프로그래밍 언어**이다.

웹 개발에서는 HTML, CSS와 함께 사용한다.

```text
HTML
→ 구조와 내용

CSS
→ 디자인과 스타일

JavaScript
→ 기능과 동작
```

JavaScript로 버튼 클릭, 입력값 처리, 서버 데이터 요청, 화면 변경 등의 기능을 구현할 수 있다.

현재는 웹뿐 아니라 서버, 데스크톱, 모바일 등 다양한 분야에서도 사용된다.

---

**2. JavaScript는 어떻게 실행될까?**

JavaScript 코드는 **JavaScript 엔진**이 실행한다.

웹 브라우저에는 JavaScript 엔진이 포함되어 있기 때문에 브라우저에서 JavaScript 코드를 실행할 수 있다.

```text
JavaScript 코드
      ↓
JavaScript 엔진
      ↓
코드 실행
```

브라우저 개발자 도구의 `Console`에서도 JavaScript를 직접 실행할 수 있다.

```javascript
console.log("안녕 자바스크립트");
```

---

**3. 핵심 정리**

* HTML은 구조, CSS는 스타일, JavaScript는 기능과 동작을 담당한다.
* JavaScript는 브라우저의 JavaScript 엔진을 통해 실행된다.
* JavaScript는 웹뿐 아니라 다양한 개발 환경에서 사용된다.
