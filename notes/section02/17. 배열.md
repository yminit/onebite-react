# Section 2 - 17. 배열

**1. 배열이란?**

배열은 **여러 값을 순서대로 저장하는 자료형**이다.

```javascript
const numbers = [1, 2, 3];
```

배열 안의 각각의 값을 **요소**라고 한다.

---

**2. 배열 만들기**

배열은 보통 대괄호 `[]`를 사용해서 만든다.

```javascript
const arr = [1, 2, 3];
```

배열에는 여러 타입의 값을 함께 넣을 수도 있다.

```javascript
const arr = [1, "hello", true, null, {}];
```

---

**3. 배열 요소 접근**

배열의 위치를 나타내는 번호를 **인덱스**라고 한다.

인덱스는 `0`부터 시작한다.

```javascript
const arr = [1, 2, 3];

console.log(arr[0]); // 1
console.log(arr[1]); // 2
```

```text
인덱스 0 → 첫 번째 요소
인덱스 1 → 두 번째 요소
인덱스 2 → 세 번째 요소
```

존재하지 않는 인덱스에 접근하면 `undefined`가 나온다.

```javascript
console.log(arr[5]); // undefined
```

---

**4. 배열 요소 수정**

인덱스를 이용해서 특정 값을 변경할 수 있다.

```javascript
const arr = [1, 2, 3];

arr[0] = "hi";

console.log(arr); // ["hi", 2, 3]
```

---

**5. 핵심 정리**

* 배열은 여러 값을 순서대로 저장한다.
* 배열 안의 값을 요소라고 한다.
* 배열은 주로 `[]`로 만든다.
* 배열의 인덱스는 `0`부터 시작한다.
* `배열[인덱스]` 형태로 값에 접근한다.
* 존재하지 않는 인덱스는 `undefined`를 반환한다.
* 인덱스를 이용해 배열 요소를 수정할 수 있다.
