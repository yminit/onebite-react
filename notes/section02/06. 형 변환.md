# Section 2 - 6. 형 변환

**1. 형 변환이란?**

형 변환은 **값의 타입을 다른 타입으로 바꾸는 것**이다.

```javascript id="1z0i9k"
let str = "10";
let num = Number(str);
```

JavaScript의 형 변환은 크게 두 가지이다.

```text id="6f6fkb"
묵시적 형 변환
명시적 형 변환
```

---

**2. 묵시적 형 변환**

JavaScript가 자동으로 타입을 변환하는 방식이다.

```javascript id="mlz8k4"
let num = 10;
let str = "20";

console.log(num + str); // "1020"
```

`+` 연산에 문자열이 포함되면 숫자가 문자열로 변환되어 연결될 수 있다.

```text id="1z0nqa"
10 + "20"
↓
"10" + "20"
↓
"1020"
```

자동 변환은 예상하지 못한 결과를 만들 수 있으므로 주의해야 한다.

---

**3. 명시적 형 변환**

개발자가 직접 타입을 변환하는 방식이다.

### a. 문자열 → 숫자

```javascript id="v9q8zc"
Number("10"); // 10
```

숫자로 변환할 수 없으면 `NaN`이 된다.

```javascript id="lzdgr4"
Number("10개"); // NaN
```

문자열 앞부분의 정수만 가져오고 싶다면 `parseInt()`를 사용할 수 있다.

```javascript id="e8jxrg"
parseInt("10개"); // 10
parseInt("개10"); // NaN
```

---

### b. 숫자 → 문자열

`String()`을 사용한다.

```javascript id="3xvcix"
let num = 20;
let str = String(num);

console.log(typeof str); // string
```

---

**4. 핵심 정리**

* 형 변환은 값의 타입을 다른 타입으로 바꾸는 것이다.
* 묵시적 형 변환은 JavaScript가 자동으로 처리한다.
* 명시적 형 변환은 개발자가 직접 처리한다.
* `Number()`는 값을 숫자로 변환한다.
* `parseInt()`는 문자열 앞부분의 정수를 변환한다.
* `String()`은 값을 문자열로 변환한다.
* 자동 형 변환보다 명시적으로 변환하는 편이 코드의 의도를 이해하기 쉽다.
