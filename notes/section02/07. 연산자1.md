# Section 2 - 7. 연산자 1

**1. 연산자란?**

연산자는 값을 계산하거나 비교하고, 변수에 값을 저장할 때 사용하는 기호이다.

```javascript
let result = 10 + 20;
```

여기서 `=`와 `+`가 연산자이다.

---

**2. 대입 연산자**

`=`는 오른쪽 값을 왼쪽 변수에 저장한다.

```javascript
let age = 27;
```

```text
age에 27 저장
```

수학의 `=`처럼 같다는 의미가 아니다.

---

**3. 산술 연산자**

숫자를 계산할 때 사용한다.

```text
+  덧셈
-  뺄셈
*  곱셈
/  나눗셈
%  나머지
```

예시:

```javascript
3 + 2; // 5
3 - 2; // 1
3 * 2; // 6
3 / 2; // 1.5
3 % 2; // 1
```

연산 순서는 일반적인 수학과 같다.

```text
괄호
↓
*, /, %
↓
+, -
```

---

**4. 복합 대입 연산자**

계산과 대입을 한 번에 처리한다.

```javascript
let num = 10;

num += 20;
```

위 코드는 다음과 같다.

```javascript
num = num + 20;
```

주요 연산자는 다음과 같다.

```text
+=
-=
*=
/=
%=
```

---

**5. 증감 연산자**

값을 `1` 증가하거나 감소시킨다.

```javascript
num++;
num--;
```

* `++`: 1 증가
* `--`: 1 감소

전위와 후위는 값을 사용하는 순서가 다르다.

```javascript
let num = 10;

let a = num++; // a: 10, num: 11
let b = ++num; // num 증가 후 b에 저장
```

```text
num++
→ 현재 값 사용 후 증가

++num
→ 먼저 증가 후 값 사용
```

---

**6. 논리 연산자**

조건을 조합하거나 반대로 만들 때 사용한다.

```text
||  OR
&&  AND
!   NOT
```

```javascript
true || false; // true
true && false; // false
!true;         // false
```

* `||`: 하나라도 참이면 `true`
* `&&`: 모두 참이어야 `true`
* `!`: 참과 거짓을 반대로 변경

---

**7. 비교 연산자**

두 값을 비교하며 결과는 `true` 또는 `false`이다.

```text
===  값과 타입이 같음
!==  값 또는 타입이 다름

>    큼
<    작음
>=   크거나 같음
<=   작거나 같음
```

예시:

```javascript
2 === 2;   // true
1 === "1"; // false
1 !== 2;   // true
2 >= 2;    // true
```

---

**8. 핵심 정리**

* `=`는 값을 저장한다.
* `+`, `-`, `*`, `/`, `%`는 산술 연산자이다.
* `+=`, `-=`, `*=`, `/=`, `%=`는 계산과 대입을 함께 처리한다.
* `++`, `--`는 값을 1 증가하거나 감소시킨다.
* `||`, `&&`, `!`는 논리 연산자이다.
* `===`, `!==`, `>`, `<`, `>=`, `<=`는 값을 비교한다.
