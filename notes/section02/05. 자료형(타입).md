# Section 2 - 5. 자료형(Type)

**1. 자료형이란?**

자료형은 **값의 종류**를 의미한다.

JavaScript의 자료형은 크게 다음 두 가지로 나눌 수 있다.

```text id="w7p4kd"
원시 타입
객체 타입
```

---

**2. 원시 타입**

대표적인 원시 타입은 다음과 같다.

```text id="c7onv3"
number
string
boolean
null
undefined
```

---

**3. number 타입**

숫자를 표현하는 타입이다.

```javascript id="w3q0fs"
let num1 = 27;
let num2 = 1.5;
let num3 = -20;
```

JavaScript에서는 정수와 실수를 따로 구분하지 않고 `number`로 다룬다.

특별한 값도 있다.

```javascript id="lt9p7x"
Infinity;
-Infinity;
NaN;
```

* `Infinity`: 양의 무한대
* `-Infinity`: 음의 무한대
* `NaN`: 숫자로 계산할 수 없는 값

```javascript id="zl8w6k"
console.log("hello" * 2); // NaN
```

---

**4. string 타입**

문자열을 표현하는 타입이다.

```javascript id="z91f2m"
let name = "이정환";
let location = "목동";
```

문자열은 `+`로 연결할 수 있지만, 변수와 함께 사용할 때는 **템플릿 리터럴**이 더 읽기 쉽다.

```javascript id="xq94hr"
let introduce = `${name}은 ${location}에 거주합니다.`;
```

템플릿 리터럴은 백틱 `` ` ``과 `${}`를 사용한다.

---

**5. boolean 타입**

참과 거짓을 표현한다.

```javascript id="zgubcb"
let isLoggedIn = true;
let isAdmin = false;
```

가능한 값은 두 개뿐이다.

```text id="1mqqwp"
true
false
```

주로 조건이나 상태를 표현할 때 사용한다.

---

**6. null과 undefined**

둘 다 값이 없음을 나타내지만 의미가 다르다.

```javascript id="vnnqia"
let empty = null;
let none;
```

```text id="n00fub"
null
→ 개발자가 의도적으로 값이 없음을 표현

undefined
→ 아직 값이 할당되지 않은 상태
```

---

**7. 객체 타입**

객체 타입은 여러 값이나 기능을 하나로 묶어 표현한다.

대표적으로 다음이 있다.

```text id="djcdyt"
객체
배열
함수
정규 표현식
```

예시:

```javascript id="utvq65"
const user = {
  name: "이정환",
  age: 27,
};

const numbers = [1, 2, 3];

function greeting() {
  console.log("안녕하세요");
}
```

배열과 함수도 JavaScript의 객체 타입에 포함된다.

---

**8. 핵심 정리**

* 자료형은 값의 종류를 의미한다.
* JavaScript 자료형은 크게 원시 타입과 객체 타입으로 나뉜다.
* `number`는 숫자를 표현한다.
* `string`은 문자열을 표현한다.
* `boolean`은 `true`, `false`를 표현한다.
* `null`은 개발자가 의도적으로 값이 없음을 나타낸다.
* `undefined`는 아직 값이 할당되지 않은 상태이다.
* 객체, 배열, 함수 등은 객체 타입에 포함된다.
