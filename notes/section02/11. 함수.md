# Section 2 - 11. 함수

**1. 함수란?**

함수는 **특정 기능을 하나로 묶어 필요할 때 실행하는 문법**이다.

중복되는 코드를 줄이고 같은 기능을 여러 번 재사용할 수 있다.

```javascript
function greeting() {
  console.log("hello");
}
```

---

**2. 함수 선언과 호출**

함수를 만드는 것을 **함수 선언**, 실제로 실행하는 것을 **함수 호출**이라고 한다.

```javascript
function greeting() {
  console.log("hello");
}

greeting();
```

```text
함수 선언
→ 실행할 코드 정의

함수 호출
→ 정의한 코드 실행
```

함수를 호출할 때는 함수 이름 뒤에 `()`를 붙인다.

---

**3. 매개변수와 인수**

함수는 외부에서 값을 전달받아 사용할 수 있다.

```javascript
function getArea(width, height) {
  return width * height;
}

getArea(10, 20);
```

* `width`, `height`: **매개변수(Parameter)**
* `10`, `20`: **인수(Argument)**

```text
인수
→ 함수를 호출할 때 전달하는 실제 값

매개변수
→ 전달받은 값을 함수 안에서 사용하는 변수
```

---

**4. return**

`return`은 함수의 결과를 밖으로 반환한다.

```javascript
function getArea(width, height) {
  return width * height;
}

const area = getArea(10, 20);

console.log(area); // 200
```

`return`이 실행되면 함수는 즉시 종료된다.

```javascript
function test() {
  return 10;

  console.log("실행되지 않음");
}
```

---

**5. 함수 재사용**

같은 함수에 다른 값을 전달해서 여러 번 사용할 수 있다.

```javascript
getArea(10, 20);   // 200
getArea(30, 20);   // 600
getArea(120, 200); // 24000
```

같은 계산 코드를 반복해서 작성하지 않아도 된다.

---

**6. 중첩 함수**

함수 안에 또 다른 함수를 만들 수도 있다.

```javascript
function outer() {
  function inner() {
    console.log("inner");
  }

  inner();
}
```

이처럼 함수 내부에 선언된 함수를 **중첩 함수**라고 한다.

---

**7. 함수 호이스팅**

함수 선언문은 선언 코드보다 위에서 호출해도 실행할 수 있다.

```javascript
greeting();

function greeting() {
  console.log("hello");
}
```

이러한 동작을 **호이스팅(Hoisting)**이라고 한다.

---

**8. 핵심 정리**

* 함수는 특정 기능을 묶어서 재사용하는 문법이다.
* 함수 선언은 기능을 정의하고, 함수 호출은 실제로 실행한다.
* 매개변수는 함수가 전달받는 값이고, 인수는 호출할 때 전달하는 실제 값이다.
* `return`은 결과를 반환하고 함수를 종료한다.
* 함수 안에 함수를 선언하면 중첩 함수라고 한다.
* 함수 선언문은 선언보다 위에서 호출할 수 있으며 이를 호이스팅이라고 한다.
