# Section 2 - 15. 객체 1

**1. 객체란?**

객체는 여러 값을 하나로 묶어서 저장하는 자료형이다.

```javascript
const person = {
  name: "이정환",
  age: 27,
  hobby: "테니스",
};
```

객체 안의 각각의 값을 **프로퍼티**라고 한다.

```text
key: value
```

---

**2. 객체 만들기**

객체는 보통 객체 리터럴 `{}`을 사용해서 만든다.

```javascript
const person = {
  name: "이정환",
  age: 27,
};
```

`new Object()`로도 만들 수 있지만 객체 리터럴을 더 자주 사용한다.

---

**3. 프로퍼티 접근하기**

객체의 값을 가져오는 방법은 두 가지이다.

### a. 점 표기법

```javascript
person.name;
person.age;
```

프로퍼티 이름을 직접 알고 있을 때 사용하기 편하다.

### b. 대괄호 표기법

```javascript
person["name"];
```

프로퍼티 이름이 변수에 들어 있거나 동적으로 결정될 때 유용하다.

```javascript
const key = "hobby";

person[key];
```

공백이 있는 프로퍼티도 대괄호 표기법을 사용한다.

```javascript
person["like cat"];
```

---

**4. 프로퍼티 추가, 수정, 삭제**

객체는 만든 뒤에도 프로퍼티를 변경할 수 있다.

```javascript
// 추가
person.favoriteFood = "떡볶이";

// 수정
person.age = 30;

// 삭제
delete person.favoriteFood;
```

`const`로 객체를 선언해도 내부 프로퍼티는 변경할 수 있다.

```javascript
const person = {
  name: "이정환",
};

person.name = "홍길동";
```

`const`는 객체 자체를 다른 값으로 다시 할당하는 것을 막는다.

---

**5. 프로퍼티 존재 여부 확인**

`in` 연산자로 특정 프로퍼티가 있는지 확인할 수 있다.

```javascript
"name" in person; // true
"address" in person; // false
```

존재하지 않는 프로퍼티에 접근하면 `undefined`가 반환된다.

```javascript
console.log(person.address); // undefined
```

---

**6. 핵심 정리**

* 객체는 여러 값을 하나로 묶어 관리하는 자료형이다.
* 객체의 값은 `key: value` 형태의 프로퍼티로 저장한다.
* 객체는 보통 `{}` 객체 리터럴로 만든다.
* 프로퍼티는 점 표기법과 대괄호 표기법으로 접근한다.
* 동적인 프로퍼티 접근에는 대괄호 표기법을 사용한다.
* 프로퍼티는 추가, 수정, 삭제할 수 있다.
* `in` 연산자로 프로퍼티 존재 여부를 확인할 수 있다.
