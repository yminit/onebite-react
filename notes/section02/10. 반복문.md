# Section 2 - 10. 반복문

**1. 반복문이란?**

반복문은 **같은 코드를 여러 번 실행할 때 사용하는 문법**이다.

대표적으로 `for` 문을 사용한다.

---

**2. for 문**

기본 구조는 다음과 같다.

```javascript
for (초기식; 조건식; 증감식) {
  반복할 코드
}
```

예시:

```javascript
for (let idx = 0; idx < 3; idx++) {
  console.log(idx);
}
```

실행 결과:

```text
0
1
2
```

동작 순서는 다음과 같다.

```text
초기식
↓
조건식 확인
↓
코드 실행
↓
증감식
↓
다시 조건식 확인
```

---

**3. continue**

`continue`는 **현재 반복을 건너뛰고 다음 반복으로 이동**한다.

```javascript
for (let idx = 0; idx < 5; idx++) {
  if (idx % 2 === 0) {
    continue;
  }

  console.log(idx);
}
```

실행 결과:

```text
1
3
```

---

**4. break**

`break`는 **반복문을 즉시 종료**한다.

```javascript
for (let idx = 0; idx < 10; idx++) {
  console.log(idx);

  if (idx >= 5) {
    break;
  }
}
```

`idx`가 `5`가 되면 반복이 종료된다.

---

**5. 핵심 정리**

* 반복문은 같은 코드를 여러 번 실행할 때 사용한다.
* `for` 문은 `초기식 → 조건식 → 실행 → 증감식` 순서로 동작한다.
* `continue`는 현재 반복을 건너뛴다.
* `break`는 반복문 전체를 종료한다.
