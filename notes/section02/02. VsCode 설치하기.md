# Section 2 - 2. Visual Studio Code 설치하기

**1. Visual Studio Code란?**

Visual Studio Code는 마이크로소프트에서 만든 **소스 코드 편집기**이다.

줄여서 `VS Code`라고 부르며, 코드를 작성하고 수정할 때 사용한다.

---

**2. 설치 방법**

공식 사이트에서 설치 파일을 내려받아 설치하면 된다.

```text
공식 사이트 접속
   ↓
설치 파일 다운로드
   ↓
설치
   ↓
VS Code 실행
```

---

**3. Extension이란?**

Extension은 VS Code에 새로운 기능을 추가하는 **확장 프로그램**이다.

`Extensions` 메뉴에서 원하는 확장 프로그램을 검색하고 설치할 수 있다.

---

**4. 추천 Extension**

* `Korean Language Pack`
  VS Code 메뉴를 한글로 변경한다.

* `Prettier`
  코드의 들여쓰기와 줄바꿈 등을 자동으로 정리한다.

* `Material Icon Theme`
  파일과 폴더를 아이콘으로 쉽게 구분할 수 있게 한다.

* `Error Lens`
  오류와 경고 내용을 코드 옆에 바로 표시한다.

* `Live Server`
  HTML 파일을 브라우저에서 실행하고 저장 시 변경 내용을 빠르게 확인할 수 있게 한다.

---

**5. 핵심 정리**

* VS Code는 코드를 작성하고 수정하는 편집기이다.
* Extension을 설치하면 필요한 기능을 추가할 수 있다.
* 자주 사용하는 확장 프로그램으로 `Prettier`, `Error Lens`, `Live Server` 등이 있다.
