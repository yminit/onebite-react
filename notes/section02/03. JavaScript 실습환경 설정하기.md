# Section 2 - 3. JavaScript 실습 환경 설정하기

**1. 실습 파일 구성**

JavaScript 실습용 `section2` 폴더를 만들고 다음 파일을 준비한다.

```text
section2
├─ index.html
└─ chapter3.js
```

---

**2. HTML과 JavaScript 연결하기**

`index.html`에서 `<script>` 태그로 JavaScript 파일을 연결한다.

```html
<script src="./chapter3.js"></script>
```

브라우저가 `index.html`을 실행하면 `chapter3.js`도 함께 불러온다.

`chapter3.js`에는 실행 확인용 코드를 작성한다.

```javascript
console.log("chapter3");
```

---

**3. Live Server로 실행하기**

VS Code에서 `index.html`을 연 뒤 Live Server를 실행한다.

```text
Ctrl + Shift + P
→ Live Server 실행
→ 브라우저 열림
```

브라우저에서는 HTML 내용이 표시되고, 개발자 도구의 `Console`에서는 JavaScript 실행 결과를 확인할 수 있다.

```text
chapter3
```

이 값이 출력되면 HTML과 JavaScript가 정상적으로 연결된 것이다.

---

**4. Live Server 종료하기**

VS Code 하단의 포트 표시를 눌러 Live Server를 종료할 수 있다.

```text
Port: 5501
```

포트 번호는 실행 환경에 따라 달라질 수 있다.

---

**5. 핵심 정리**

* HTML과 JavaScript 파일을 만든다.
* `<script>` 태그로 JavaScript 파일을 연결한다.
* Live Server로 브라우저에서 실행한다.
* 개발자 도구 `Console`에서 JavaScript 실행 결과를 확인한다.
