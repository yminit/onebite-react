# Section 2 - 8. 연산자 2

**1. null 병합 연산자 `??`**

`??`는 왼쪽 값이 `null` 또는 `undefined`일 때 오른쪽 값을 사용한다.

```javascript
let name = null;
let nickname = "winter";

let displayName = name ?? nickname;

console.log(displayName); // "winter"
```

중요한 점은 `0`, `""`, `false`는 값이 있는 것으로 본다는 것이다.

```javascript
0 ?? 10;        // 0
"" ?? "기본값"; // ""
false ?? true;  // false
```

---

**2. typeof 연산자**

`typeof`는 값의 타입을 문자열로 반환한다.

```javascript
typeof 10;        // "number"
typeof "hello";   // "string"
typeof true;      // "boolean"
typeof undefined; // "undefined"
```

변수에 저장된 값이 바뀌면 결과도 달라질 수 있다.

```javascript
let value = 1;

value = "hello";

console.log(typeof value); // "string"
```

---

**3. 삼항 연산자**

삼항 연산자는 조건에 따라 두 값 중 하나를 선택할 때 사용한다.

```javascript
조건식 ? 참일 때 값 : 거짓일 때 값
```

예시:

```javascript
let num = 10;

let result = num % 2 === 0 ? "짝수" : "홀수";

console.log(result); // "짝수"
```

```text
조건이 true
→ ? 뒤의 값

조건이 false
→ : 뒤의 값
```

---

**4. 핵심 정리**

* `??`는 `null`, `undefined`일 때 기본값을 선택한다.
* `0`, `""`, `false`는 `??`에서 정상적인 값으로 처리한다.
* `typeof`는 값의 타입을 문자열로 반환한다.
* 삼항 연산자는 `조건 ? 참 : 거짓` 형태로 사용한다.
