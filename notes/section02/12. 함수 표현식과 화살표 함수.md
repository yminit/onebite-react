# Section 2 - 12. 함수 표현식과 화살표 함수

**1. 함수 선언문**

`function` 키워드로 함수를 직접 선언하는 방식이다.

```javascript id="y4h8kw"
function funcA() {
  console.log("funcA");
}

funcA();
```

함수 선언문은 **호이스팅**이 적용되어 선언보다 위에서 호출할 수도 있다.

---

**2. 함수 표현식**

함수를 값처럼 변수에 저장하는 방식이다.

```javascript id="kz8gq1"
const funcB = function () {
  console.log("funcB");
};

funcB();
```

이름이 없는 함수를 **익명 함수**라고 한다.

함수 자체를 다른 변수에 저장할 때는 `()`를 붙이지 않는다.

```javascript id="m6h3pf"
const another = funcA;
```

반대로

```javascript id="v3epj7"
const result = funcA();
```

처럼 작성하면 함수를 실행한 뒤 **반환값**이 저장된다.

함수 표현식은 변수에 함수가 저장된 이후에 호출해야 한다.

---

**3. 화살표 함수**

화살표 함수는 `=>`를 사용해 함수를 간결하게 작성하는 방식이다.

```javascript id="u2xk49"
const add = (value) => {
  return value + 1;
};
```

반환문이 한 줄이라면 더 짧게 작성할 수 있다.

```javascript id="l9pr2c"
const add = (value) => value + 1;
```

```text id="t0wb5e"
중괄호 사용
→ return 직접 작성

중괄호 없이 표현식 작성
→ 결과 자동 반환
```

---

**4. 차이 정리**

```text id="z8dq4s"
함수 선언문
→ function으로 직접 선언
→ 호이스팅 가능

함수 표현식
→ 함수를 변수에 저장
→ 변수 선언 이후 호출

화살표 함수
→ => 사용
→ 짧고 간결하게 작성 가능
```

화살표 함수는 일반 함수와 달리 **자신만의 `this`를 만들지 않고**, 생성자 함수로 사용할 수 없다.

---

**5. 핵심 정리**

* JavaScript에서는 함수도 값처럼 변수에 저장할 수 있다.
* 함수 선언문은 `function`으로 직접 선언한다.
* 함수 표현식은 함수를 변수에 저장하는 방식이다.
* 함수 이름 뒤에 `()`가 없으면 함수 자체를 가리키고, `()`가 있으면 함수를 실행한다.
* 화살표 함수는 `=>`를 사용해 함수를 간결하게 작성한다.
* 한 줄 반환은 `{}`와 `return`을 생략할 수 있다.
