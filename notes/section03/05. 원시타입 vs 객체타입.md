# Section 3 - 5. 원시 타입 vs 객체 타입

**1. 핵심 차이**

원시 타입과 객체 타입은 **값을 저장하고 복사하는 방식**이 다르다.

```text
원시 타입
→ 값 자체를 저장

객체 타입
→ 객체를 가리키는 참조값을 저장
```

---

**2. 원시 타입**

원시 타입은 값을 복사하면 서로 독립적인 값이 된다.

```javascript
let a = 10;
let b = a;

b = 20;

console.log(a); // 10
console.log(b); // 20
```

`b`를 변경해도 `a`에는 영향을 주지 않는다.

원시 타입의 값은 **불변값(Immutable)**이다.

```javascript
let a = 10;
a = 20;
```

기존 `10`을 수정하는 것이 아니라 새로운 값 `20`을 다시 할당한다고 이해하면 된다.

---

**3. 객체 타입**

객체를 다른 변수에 할당하면 **참조값이 복사**된다.

```javascript
const obj1 = {
  name: "이정환",
};

const obj2 = obj1;

obj2.name = "홍길동";

console.log(obj1.name); // 홍길동
```

```text
obj1 ─┐
      ├→ 같은 객체
obj2 ─┘
```

두 변수가 같은 객체를 가리키기 때문에 한쪽에서 수정하면 다른 쪽에서도 변경된 값이 보인다.

---

**4. 객체 복사**

Spread를 사용하면 새로운 객체를 만들 수 있다.

```javascript
const obj1 = {
  name: "이정환",
  age: 27,
};

const obj2 = {
  ...obj1,
};

obj2.age = 30;

console.log(obj1.age); // 27
console.log(obj2.age); // 30
```

하지만 Spread는 **얕은 복사**이므로 중첩 객체는 참조를 공유할 수 있다.

```javascript
const obj1 = {
  address: {
    city: "서울",
  },
};

const obj2 = {
  ...obj1,
};

obj2.address.city = "부산";

console.log(obj1.address.city); // 부산
```

---

**5. 객체 비교**

객체의 `===` 비교는 내용이 아니라 **같은 객체를 가리키는지** 비교한다.

```javascript
const obj1 = { name: "이정환" };
const obj2 = obj1;

console.log(obj1 === obj2); // true
```

각각 새로 만든 객체라면 내용이 같아도 `false`이다.

```javascript
const obj1 = { name: "이정환" };
const obj2 = { name: "이정환" };

console.log(obj1 === obj2); // false
```

---

**6. 배열과 함수**

배열과 함수도 객체 타입에 포함된다.

따라서 배열도 같은 참조 특성을 가진다.

```javascript
const arr1 = [1, 2, 3];
const arr2 = arr1;

arr2[0] = 100;

console.log(arr1); // [100, 2, 3]
```

---

**7. 핵심 정리**

* 원시 타입은 값 자체를 저장하고 복사한다.
* 원시 타입을 복사하면 서로 독립적이다.
* 객체 타입은 참조값을 저장하고 복사한다.
* 객체 참조를 복사하면 같은 객체를 공유한다.
* Spread로 새로운 객체를 만들 수 있지만 이는 얕은 복사이다.
* 객체의 `===` 비교는 내용이 아니라 참조값을 비교한다.
* 배열과 함수도 객체 타입에 포함된다.
