# Section 3 - 1. Truthy와 Falsy

**1. Truthy와 Falsy란?**

JavaScript에서는 `true`, `false`가 아닌 값도 조건문에서 참 또는 거짓처럼 평가된다.

```javascript
if ("hello") {
  console.log("실행됨");
}
```

`"hello"`는 불리언 값은 아니지만 참으로 평가된다.

JavaScript의 값은 조건식에서 크게 두 종류로 나뉜다.

```text
Truthy
Falsy
```

---

**2. Falsy 값**

Falsy는 조건문에서 `false`로 평가되는 값이다.

대표적인 값은 다음과 같다.

```javascript
undefined
null
0
-0
NaN
""
0n
```

예시:

```javascript
if (0) {
  console.log("실행되지 않음");
}
```

`Boolean()`으로 확인할 수도 있다.

```javascript
Boolean(0);  // false
Boolean(""); // false
```

---

**3. Truthy 값**

Falsy가 아닌 값은 대부분 Truthy이다.

```javascript
Boolean("hello"); // true
Boolean(123);     // true
Boolean([]);      // true
Boolean({});      // true
```

특히 주의할 점은 **빈 배열 `[]`과 빈 객체 `{}`도 Truthy**라는 것이다.

```text
""  → Falsy
[]  → Truthy
{}  → Truthy
```

---

**4. 활용하기**

Truthy와 Falsy를 이용하면 값이 있는지 간단하게 확인할 수 있다.

```javascript
function printName(person) {
  if (!person) {
    console.log("person의 값이 없음");
    return;
  }

  console.log(person.name);
}
```

`person`이 `undefined`, `null` 같은 Falsy 값이면 먼저 함수를 종료한다.

```text
person이 Falsy
→ !person은 true
→ 값이 없는 경우 처리
```

이렇게 하면 값이 없는 상태에서 프로퍼티에 접근하는 오류를 예방할 수 있다.

---

**5. 핵심 정리**

* JavaScript에서는 불리언이 아닌 값도 참/거짓으로 평가된다.
* `undefined`, `null`, `0`, `-0`, `NaN`, `""`, `0n`은 Falsy이다.
* Falsy가 아닌 값은 대부분 Truthy이다.
* 빈 배열 `[]`과 빈 객체 `{}`는 Truthy이다.
* `Boolean()`으로 Truthy/Falsy 여부를 확인할 수 있다.
* `if (!값)` 형태로 값이 없는 경우를 간단하게 처리할 수 있다.
