# Section 3 - 11. 동기와 비동기

**1. 동기란?**

동기는 **앞의 작업이 끝난 뒤 다음 작업을 실행하는 방식**이다.

```javascript
console.log(1);
console.log(2);
console.log(3);
```

실행 결과:

```text
1
2
3
```

JavaScript 코드는 기본적으로 위에서 아래로 순서대로 실행된다.

---

**2. JavaScript와 싱글 쓰레드**

쓰레드는 프로그램에서 작업을 실행하는 흐름이다.

JavaScript 엔진은 기본적으로 **하나의 쓰레드에서 JavaScript 코드를 실행**한다.

```text
작업 1
↓
작업 2
↓
작업 3
```

따라서 오래 걸리는 작업이 있으면 뒤의 작업도 기다려야 할 수 있다.

---

**3. 비동기란?**

비동기는 오래 걸리는 작업을 기다리는 동안 **다른 작업을 먼저 실행할 수 있는 방식**이다.

대표적인 예가 `setTimeout()`이다.

```javascript
console.log(1);

setTimeout(() => {
  console.log(2);
}, 3000);

console.log(3);
```

실행 결과:

```text
1
3
2
```

`setTimeout()`을 만났다고 해서 JavaScript가 3초 동안 멈추는 것은 아니다.

---

**4. setTimeout() 동작**

`setTimeout()`은 일정 시간이 지난 뒤 콜백 함수가 실행되도록 예약한다.

```javascript
setTimeout(() => {
  console.log(2);
}, 3000);
```

브라우저에서는 타이머 작업을 **Web APIs**가 처리한다.

```text
console.log(1)
↓
1 출력

setTimeout()
↓
Web APIs에 타이머 작업 맡김

console.log(3)
↓
3 출력

타이머 완료
↓
콜백 함수 실행
↓
2 출력
```

---

**5. Web APIs**

Web APIs는 브라우저가 JavaScript에 제공하는 기능이다.

대표적으로 다음과 같은 작업이 있다.

```text
타이머
→ setTimeout()

사용자 이벤트
→ 클릭, 키보드 입력

네트워크 요청
→ 서버와 데이터 통신
```

JavaScript는 이런 작업을 맡긴 뒤 다른 코드를 계속 실행할 수 있다.

---

**6. 동기와 비동기 구분**

```text
동기
→ 앞 작업 완료
→ 다음 작업 실행

비동기
→ 오래 걸리는 작업을 맡김
→ 다른 작업 먼저 실행
→ 완료된 작업을 나중에 처리
```

---

**7. 핵심 정리**

* 동기는 작업을 순서대로 처리한다.
* JavaScript 엔진은 기본적으로 싱글 쓰레드로 코드를 실행한다.
* 오래 걸리는 동기 작업은 뒤의 코드 실행을 지연시킬 수 있다.
* 비동기는 작업을 기다리는 동안 다른 코드를 실행할 수 있다.
* `setTimeout()`은 대표적인 비동기 처리 예시이다.
* 브라우저에서는 Web APIs가 타이머, 이벤트, 네트워크 작업 등을 처리하는 데 도움을 준다.
* 비동기 작업이 완료되면 등록한 콜백 함수가 나중에 실행된다.
