# Section 3 - 4. Spread 연산자와 Rest 매개변수

**1. Spread 연산자**

Spread 연산자는 배열이나 객체의 값을 **펼쳐서 사용하는 문법**이다.

`...`을 사용한다.

### a. 배열

```javascript id="6v5m2z"
const arr1 = [1, 2, 3];

const arr2 = [4, ...arr1, 5];

console.log(arr2); // [4, 1, 2, 3, 5]
```

### b. 객체

```javascript id="d56xaz"
const obj1 = {
  a: 1,
  b: 2,
};

const obj2 = {
  ...obj1,
  c: 3,
};
```

### c. 함수 호출

배열의 값을 각각의 인수로 전달할 수도 있다.

```javascript id="tb5pxn"
const arr = [1, 2, 3];

function func(a, b, c) {
  console.log(a, b, c);
}

func(...arr); // func(1, 2, 3)
```

---

**2. Rest 매개변수**

Rest 매개변수는 함수에 전달된 **남은 인수들을 배열로 모아서 받는 문법**이다.

```javascript id="gn8a0y"
function func(one, two, ...rest) {
  console.log(rest);
}

func(1, 2, 3, 4, 5);
```

실행 결과:

```text id="4b3xpy"
[3, 4, 5]
```

Rest 매개변수는 반드시 마지막에 작성해야 한다.

```javascript id="vse74q"
function func(one, two, ...rest) {}
```

---

**3. Spread와 Rest 차이**

같은 `...`을 사용하지만 역할은 반대이다.

```text id="zw0xao"
Spread
[1, 2, 3]
→ 1, 2, 3

Rest
1, 2, 3
→ [1, 2, 3]
```

* Spread: 값을 펼친다.
* Rest: 남은 값을 모은다.

---

**4. 함께 사용하기**

```javascript id="0mg81n"
const arr = [1, 2, 3];

function func(one, two, ...rest) {
  console.log(one);
  console.log(two);
  console.log(rest);
}

func(...arr);
```

```text id="bh7u9h"
...arr
→ Spread로 1, 2, 3을 펼침

...rest
→ 남은 3을 [3]으로 모음
```

---

**5. 핵심 정리**

* Spread와 Rest 모두 `...`을 사용한다.
* Spread는 배열이나 객체의 값을 펼친다.
* 함수 호출에서도 배열을 여러 인수로 펼칠 수 있다.
* Rest 매개변수는 남은 인수를 배열로 모은다.
* Rest 매개변수는 반드시 마지막에 작성한다.
