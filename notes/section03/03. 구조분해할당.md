# Section 3 - 3. 구조 분해 할당

**1. 구조 분해 할당이란?**

배열이나 객체의 값을 꺼내서 여러 변수에 한 번에 저장하는 문법이다.

```javascript
const arr = [1, 2, 3];

const [one, two, three] = arr;
```

---

**2. 배열 구조 분해 할당**

배열은 **순서대로** 값을 꺼낸다.

```javascript
const arr = [1, 2, 3];

const [one, two, three] = arr;

console.log(one, two, three); // 1 2 3
```

값이 없을 경우 기본값을 지정할 수도 있다.

```javascript
const [one, two, three, four = 4] = [1, 2, 3];

console.log(four); // 4
```

---

**3. 객체 구조 분해 할당**

객체는 **프로퍼티 이름을 기준으로** 값을 꺼낸다.

```javascript
const person = {
  name: "이정환",
  age: 27,
  hobby: "테니스",
};

const { name, age, hobby } = person;
```

기존 방식과 비교하면 다음과 같다.

```javascript
const name = person.name;
const age = person.age;
const hobby = person.hobby;
```

객체에서도 기본값을 지정할 수 있다.

```javascript
const { name, extra = "hello" } = person;
```

---

**4. 함수 매개변수에서 사용하기**

객체를 전달받을 때 매개변수에서 바로 구조 분해할 수 있다.

```javascript
const printPerson = ({ name, age, hobby }) => {
  console.log(name, age, hobby);
};

printPerson(person);
```

이렇게 하면 함수 내부에서 `person.name`처럼 객체 이름을 반복해서 작성하지 않아도 된다.

---

**5. 배열과 객체의 차이**

```text
배열
→ 순서를 기준으로 분해
→ []

객체
→ 프로퍼티 이름을 기준으로 분해
→ {}
```

---

**6. 핵심 정리**

* 구조 분해 할당은 배열이나 객체의 값을 변수로 꺼내는 문법이다.
* 배열은 순서를 기준으로 값을 가져온다.
* 객체는 프로퍼티 이름을 기준으로 값을 가져온다.
* 값이 `undefined`이면 기본값을 사용할 수 있다.
* 함수의 매개변수에서도 구조 분해 할당을 사용할 수 있다.
