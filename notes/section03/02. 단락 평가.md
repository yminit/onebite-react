# Section 3 - 2. 단락 평가

**1. 단락 평가란?**

단락 평가는 논리 연산에서 **왼쪽 값만으로 결과를 결정할 수 있으면 오른쪽 값을 확인하지 않는 동작**이다.

주로 `&&`, `||`에서 발생한다.

---

**2. AND 연산자 `&&`**

`&&`는 왼쪽 값이 Falsy이면 오른쪽을 확인하지 않는다.

```javascript
0 && 20; // 0
```

왼쪽 값이 Truthy이면 오른쪽까지 확인한다.

```javascript
10 && 20; // 20
```

```text
Falsy && 값
→ 왼쪽 값 반환

Truthy && 값
→ 오른쪽 값 반환
```

---

**3. OR 연산자 `||`**

`||`는 왼쪽 값이 Truthy이면 오른쪽을 확인하지 않는다.

```javascript
10 || 20; // 10
```

왼쪽 값이 Falsy이면 오른쪽까지 확인한다.

```javascript
0 || 20; // 20
```

```text
Truthy || 값
→ 왼쪽 값 반환

Falsy || 값
→ 오른쪽 값 반환
```

---

**4. 논리 연산자는 실제 값을 반환한다**

`&&`, `||`는 항상 `true`, `false`만 반환하는 것이 아니다.

```javascript
10 && 20; // 20
0 && 20;  // 0

10 || 20; // 10
0 || 20;  // 20
```

즉, **연산이 결정되는 위치의 실제 값**을 반환한다.

---

**5. 활용하기**

단락 평가를 이용하면 값이 있을 때만 다음 코드에 접근할 수 있다.

```javascript
function printName(person) {
  const name = person && person.name;

  console.log(name || "person의 값이 없음");
}
```

```text
person이 Falsy
→ person.name에 접근하지 않음

name이 Falsy
→ 기본 문구 사용
```

---

**6. 핵심 정리**

* 단락 평가는 결과가 결정되면 뒤의 값을 확인하지 않는 동작이다.
* `&&`는 처음 만나는 Falsy 값 또는 마지막 값을 반환한다.
* `||`는 처음 만나는 Truthy 값 또는 마지막 값을 반환한다.
* 논리 연산자는 실제 값을 반환할 수 있다.
* 단락 평가를 이용해 조건부 실행이나 기본값 처리가 가능하다.
