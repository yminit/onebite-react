# Section 3 - 14. 비동기 작업 처리하기 3. Async & Await

**1. async**

`async`를 붙인 함수는 **항상 Promise를 반환**한다.

```javascript id="f6z9wa"
async function getData() {
  return "hello";
}

getData().then((result) => {
  console.log(result); // hello
});
```

일반 값을 반환해도 Promise로 처리된다.

---

**2. await**

`await`는 Promise가 완료될 때까지 기다린 뒤 **성공 결과를 가져온다.**

```javascript id="d9px4v"
async function printData() {
  const data = await getData();

  console.log(data);
}
```

```text id="9rc4ye"
Promise 반환
→ await
→ 작업 완료
→ 결과값 반환
```

`await`는 기본적으로 `async` 함수 안에서 사용한다.

---

**3. async와 await 함께 사용하기**

```javascript id="h3wkm1"
function getData() {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve({
        name: "이정환",
        id: "winterlood",
      });
    }, 1500);
  });
}

async function printData() {
  const data = await getData();

  console.log(data);
}

printData();
```

`await`가 없으면 실제 결과가 아니라 Promise 객체를 받는다.

```javascript id="0kq8fb"
const data = getData();
// data → Promise
```

---

**4. await는 JavaScript 전체를 멈추지 않는다**

`await`는 **현재 async 함수의 이후 코드만 기다리게 한다.**

```javascript id="3x6tcy"
async function printData() {
  console.log("A");

  const data = await getData();

  console.log(data);
  console.log("B");
}

printData();

console.log("C");
```

실행 흐름:

```text id="ks3az6"
A
C
비동기 작업 완료
B
```

`await`를 기다리는 동안 함수 바깥의 다른 코드는 계속 실행될 수 있다.

---

**5. 여러 비동기 작업 순서대로 처리하기**

```javascript id="53vbxp"
async function run() {
  const result1 = await add10(0);
  console.log(result1); // 10

  const result2 = await add10(result1);
  console.log(result2); // 20

  const result3 = await add10(result2);
  console.log(result3); // 30
}
```

Promise 체이닝보다 위에서 아래로 읽기 쉬운 형태로 작성할 수 있다.

---

**6. Promise와의 관계**

```text id="dwy4or"
Promise
→ then(), catch()로 처리

async/await
→ Promise를 더 읽기 쉽게 사용하는 문법
```

`async/await`는 Promise를 대체하는 것이 아니라 **Promise를 기반으로 동작한다.**

---

**7. 핵심 정리**

* `async` 함수는 항상 Promise를 반환한다.
* `await`는 Promise의 완료를 기다리고 결과를 가져온다.
* `await`는 기본적으로 `async` 함수 내부에서 사용한다.
* `await`가 JavaScript 전체 실행을 멈추는 것은 아니다.
* 여러 비동기 작업을 순서대로 처리할 때 코드가 읽기 쉬워진다.
* `async/await`는 Promise를 더 편하게 사용하는 문법이다.
