# Section 3 - 10. Date 객체와 날짜

**1. Date 객체란?**

`Date` 객체는 JavaScript에서 **날짜와 시간을 다룰 때 사용하는 객체**이다.

```javascript id="pl7j3n"
const now = new Date();
```

값을 전달하지 않으면 현재 날짜와 시간이 생성된다.

---

**2. 특정 날짜 만들기**

```javascript id="4d9fbz"
const date = new Date("1997-01-07 10:10:10");
```

날짜 문자열 형식에 따라 해석이 달라질 수 있으므로 형식은 명확하게 작성하는 것이 좋다.

---

**3. 타임스탬프**

타임스탬프는 **1970년 1월 1일 00:00:00 UTC부터 지난 시간을 밀리초로 나타낸 값**이다.

```javascript id="z8wt9x"
const date = new Date();

const timestamp = date.getTime();
```

타임스탬프로 다시 `Date` 객체를 만들 수도 있다.

```javascript id="qn6ih8"
const newDate = new Date(timestamp);
```

```text id="p89l3t"
Date 객체
→ getTime()
→ 타임스탬프
→ new Date()
→ Date 객체
```

---

**4. 날짜와 시간 가져오기**

```javascript id="8g3nha"
const date = new Date();

date.getFullYear(); // 연도
date.getMonth();    // 월
date.getDate();     // 일

date.getHours();    // 시
date.getMinutes();  // 분
date.getSeconds();  // 초
```

주의할 점은 `getMonth()`가 `0`부터 시작한다는 것이다.

```javascript id="k37rpf"
const month = date.getMonth() + 1;
```

```text id="d6aoys"
0  → 1월
1  → 2월
...
11 → 12월
```

---

**5. 날짜와 시간 수정하기**

`set`으로 시작하는 메서드를 사용한다.

```javascript id="j592z1"
date.setFullYear(2023);
date.setMonth(2);
date.setDate(20);

date.setHours(10);
date.setMinutes(49);
date.setSeconds(59);
```

`setMonth()` 역시 `0`부터 시작하므로 `2`는 3월이다.

---

**6. 문자열로 변환하기**

```javascript id="mpxgqe"
date.toDateString();
```

날짜 부분을 문자열로 반환한다.

```javascript id="l4phhr"
date.toLocaleString();
```

실행 환경의 지역 설정에 맞게 날짜와 시간을 문자열로 반환한다.

---

**7. 핵심 정리**

* `Date` 객체는 날짜와 시간을 다룰 때 사용한다.
* `new Date()`는 현재 날짜와 시간을 생성한다.
* `getTime()`은 시간을 타임스탬프로 반환한다.
* `getFullYear()`, `getMonth()`, `getDate()` 등으로 날짜 정보를 가져온다.
* `getMonth()`와 `setMonth()`는 `0`부터 시작한다.
* `set...()` 메서드로 날짜와 시간을 수정할 수 있다.
* `toDateString()`, `toLocaleString()`으로 문자열 형태로 변환할 수 있다.
