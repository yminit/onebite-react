# Section 3 - 9. 배열 메서드 3. 배열 변형

**1. filter()**

조건을 만족하는 요소만 골라 **새로운 배열**로 반환한다.

```javascript
const numbers = [1, 2, 3, 4];

const evenNumbers = numbers.filter(
  (item) => item % 2 === 0
);

console.log(evenNumbers); // [2, 4]
```

---

**2. map()**

모든 요소를 새로운 값으로 변환해서 **새로운 배열**로 반환한다.

```javascript
const numbers = [1, 2, 3];

const doubled = numbers.map(
  (item) => item * 2
);

console.log(doubled); // [2, 4, 6]
```

```text
filter()
→ 필요한 요소를 선택

map()
→ 모든 요소를 변환
```

---

**3. sort()**

배열을 정렬하며 **원본 배열을 변경한다.**

```javascript
const numbers = [10, 3, 5];

numbers.sort((a, b) => a - b);

console.log(numbers); // [3, 5, 10]
```

숫자 정렬은 보통 다음처럼 작성한다.

```javascript
// 오름차순
numbers.sort((a, b) => a - b);

// 내림차순
numbers.sort((a, b) => b - a);
```

비교 함수를 전달하지 않으면 문자열처럼 비교하여 정렬한다.

---

**4. toSorted()**

`sort()`처럼 정렬하지만 **원본 배열을 변경하지 않고 새로운 배열을 반환한다.**

```javascript
const arr = ["c", "a", "b"];

const sorted = arr.toSorted();

console.log(arr);    // ["c", "a", "b"]
console.log(sorted); // ["a", "b", "c"]
```

```text
sort()
→ 원본 변경

toSorted()
→ 원본 유지 + 새로운 배열 반환
```

---

**5. join()**

배열의 요소를 연결해서 하나의 문자열로 반환한다.

```javascript
const words = ["hi", "im", "winterlood"];

const result = words.join("-");

console.log(result);
// hi-im-winterlood
```

전달한 문자열이 요소 사이의 구분자가 된다.

---

**6. 핵심 정리**

* `filter()`는 조건에 맞는 요소만 선택한다.
* `map()`은 모든 요소를 새로운 값으로 변환한다.
* `sort()`는 원본 배열을 직접 정렬한다.
* `toSorted()`는 원본을 유지하면서 정렬된 새 배열을 만든다.
* `join()`은 배열의 요소를 하나의 문자열로 연결한다.
