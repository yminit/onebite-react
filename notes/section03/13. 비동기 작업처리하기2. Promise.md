# Section 3 - 13. 비동기 작업 처리하기 2. Promise

**1. Promise란?**

`Promise`는 비동기 작업의 **상태와 결과를 관리하는 객체**이다.

콜백 중첩을 줄이고 비동기 흐름을 더 읽기 쉽게 만들 수 있다.

---

**2. Promise의 상태**

Promise는 3가지 상태를 가진다.

```text id="p9cx1a"
Pending
→ 작업 중

Fulfilled
→ 작업 성공

Rejected
→ 작업 실패
```

성공하면 `resolve()`, 실패하면 `reject()`를 호출한다.

```javascript id="n5qw7d"
const promise = new Promise((resolve, reject) => {
  if (작업성공) {
    resolve(결과);
  } else {
    reject(에러);
  }
});
```

---

**3. Promise 생성**

`new Promise()`에 전달하는 함수를 `executor`라고 한다.

```javascript id="r4b1yx"
const promise = new Promise((resolve, reject) => {
  // 비동기 작업
});
```

예시:

```javascript id="f8t0lm"
function add10(num) {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (typeof num === "number") {
        resolve(num + 10);
      } else {
        reject("num이 숫자가 아님");
      }
    }, 1000);
  });
}
```

---

**4. then()과 catch()**

`then()`은 성공 결과를 처리한다.

```javascript id="7mq48p"
add10(0).then((result) => {
  console.log(result); // 10
});
```

`catch()`는 실패 결과를 처리한다.

```javascript id="gk9v2s"
add10("hello").catch((err) => {
  console.log(err);
});
```

```text id="j3e8tf"
resolve(값)
→ then()으로 전달

reject(값)
→ catch()로 전달
```

---

**5. Promise 체이닝**

`then()`에서 새로운 Promise를 반환하면 다음 비동기 작업을 연결할 수 있다.

```javascript id="q6kh2a"
add10(0)
  .then((result) => {
    console.log(result); // 10
    return add10(result);
  })
  .then((result) => {
    console.log(result); // 20
  })
  .catch((err) => {
    console.log(err);
  });
```

흐름은 다음과 같다.

```text id="xm6r0c"
add10(0)
→ 10
→ add10(10)
→ 20
```

이처럼 Promise를 연속해서 연결하는 것을 **Promise 체이닝**이라고 한다.

---

**6. 콜백 방식과의 차이**

```text id="p8q2cv"
콜백
→ 함수 안에 함수가 계속 중첩될 수 있음

Promise
→ then()을 이어서 순서대로 작성 가능
```

체이닝 마지막에 `catch()`를 연결하면 앞에서 발생한 실패를 처리할 수 있다.

---

**7. 핵심 정리**

* `Promise`는 비동기 작업의 상태와 결과를 관리한다.
* 상태는 `Pending`, `Fulfilled`, `Rejected`가 있다.
* `resolve()`는 성공, `reject()`는 실패를 의미한다.
* `then()`은 성공 결과를 처리한다.
* `catch()`는 실패 결과를 처리한다.
* `then()`에서 Promise를 반환하면 다음 비동기 작업을 연결할 수 있다.
* 이를 Promise 체이닝이라고 하며 콜백 중첩을 줄일 수 있다.
