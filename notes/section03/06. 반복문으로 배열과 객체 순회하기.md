# Section 3 - 6. 반복문으로 배열과 객체 순회하기

**1. 순회란?**

순회는 배열이나 객체의 값을 **하나씩 꺼내서 확인하는 것**이다.

---

**2. 배열 순회**

### a. 기본 `for`

인덱스가 필요할 때 사용한다.

```javascript
const arr = [1, 2, 3];

for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]);
}
```

`arr.length`는 배열 요소의 개수이다.

### b. `for...of`

배열의 값만 필요하다면 더 간단하게 사용할 수 있다.

```javascript
const arr = [1, 2, 3];

for (const item of arr) {
  console.log(item);
}
```

```text
for
→ 인덱스 사용 가능

for...of
→ 배열의 값을 바로 꺼냄
```

---

**3. 객체 순회**

객체는 인덱스가 없기 때문에 `key`나 `value`를 기준으로 순회한다.

```javascript
const person = {
  name: "이정환",
  age: 27,
  hobby: "테니스",
};
```

### a. `Object.keys()`

객체의 `key`를 배열로 반환한다.

```javascript
const keys = Object.keys(person);

console.log(keys);
// ["name", "age", "hobby"]
```

`key`를 이용하면 값에도 접근할 수 있다.

```javascript
for (const key of Object.keys(person)) {
  console.log(key, person[key]);
}
```

### b. `Object.values()`

객체의 `value`를 배열로 반환한다.

```javascript
const values = Object.values(person);

for (const value of values) {
  console.log(value);
}
```

### c. `for...in`

객체의 `key`를 하나씩 순회한다.

```javascript
for (const key in person) {
  console.log(key, person[key]);
}
```

---

**4. 구분해서 기억하기**

```text
배열 값 순회
→ for...of

객체 key 순회
→ for...in

객체 key 배열
→ Object.keys()

객체 value 배열
→ Object.values()
```

---

**5. 핵심 정리**

* 순회는 여러 값에 하나씩 접근하는 것이다.
* 배열은 `for` 또는 `for...of`로 순회할 수 있다.
* `for...of`는 배열의 값을 바로 가져온다.
* `Object.keys()`는 객체의 key를 배열로 반환한다.
* `Object.values()`는 객체의 value를 배열로 반환한다.
* `for...in`은 객체의 key를 순회한다.
* 객체의 값은 `객체[key]` 형태로 가져올 수 있다
