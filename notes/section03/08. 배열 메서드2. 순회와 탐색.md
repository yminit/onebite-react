# Section 3 - 8. 배열 메서드 2. 순회와 탐색

**1. forEach()**

배열의 모든 요소를 순회하면서 콜백 함수를 실행한다.

```javascript
const arr = [1, 2, 3];

arr.forEach((item, index) => {
  console.log(index, item);
});
```

콜백에서 주로 사용하는 값은 다음과 같다.

```text
item  → 현재 요소
index → 현재 인덱스
```

---

**2. includes()**

배열에 특정 값이 있는지 확인한다.

```javascript
const arr = [1, 2, 3];

arr.includes(2);  // true
arr.includes(10); // false
```

반환값은 `true` 또는 `false`이다.

---

**3. indexOf()**

특정 값의 인덱스를 찾는다.

```javascript
const arr = [1, 2, 3];

arr.indexOf(2);  // 1
arr.indexOf(10); // -1
```

찾지 못하면 `-1`을 반환한다.

---

**4. findIndex()**

조건을 처음 만족하는 요소의 **인덱스**를 반환한다.

```javascript
const arr = [2, 4, 5, 7];

const index = arr.findIndex(
  (item) => item % 2 !== 0
);

console.log(index); // 2
```

조건을 만족하는 요소가 없으면 `-1`을 반환한다.

---

**5. find()**

조건을 처음 만족하는 **요소 자체**를 반환한다.

```javascript
const people = [
  { name: "이정환" },
  { name: "홍길동" },
];

const person = people.find(
  (item) => item.name === "홍길동"
);

console.log(person);
// { name: "홍길동" }
```

찾지 못하면 `undefined`를 반환한다.

---

**6. 메서드 구분**

```text
forEach()
→ 모든 요소 순회

includes()
→ 특정 값이 있는지 확인

indexOf()
→ 특정 값의 인덱스 찾기

findIndex()
→ 조건에 맞는 요소의 인덱스 찾기

find()
→ 조건에 맞는 요소 자체 찾기
```

특히 다음 차이를 기억하면 된다.

```text
indexOf()
→ 값을 직접 찾음

findIndex()
→ 조건으로 찾음

find()
→ 조건에 맞는 요소 자체를 반환
```

---

**7. 핵심 정리**

* `forEach()`는 모든 요소를 순회한다.
* `includes()`는 특정 값의 존재 여부를 확인한다.
* `indexOf()`는 특정 값의 인덱스를 반환한다.
* `findIndex()`는 조건을 만족하는 첫 번째 요소의 인덱스를 반환한다.
* `find()`는 조건을 만족하는 첫 번째 요소 자체를 반환한다.
* `indexOf()`, `findIndex()`는 찾지 못하면 `-1`을 반환한다.
* `find()`는 찾지 못하면 `undefined`를 반환한다.
