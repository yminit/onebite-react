# Section 10 - 1. useReducer

**1. useReducer란?**

`useReducer`는 `useState`처럼 State를 관리하는 Hook이다.

차이는 **상태 변경 로직을 `reducer` 함수로 분리할 수 있다는 점**이다.

```text
useState
→ 컴포넌트 안에서 State 변경

useReducer
→ dispatch로 변경 요청
→ reducer에서 상태 변경 계산
```

상태 변경 종류가 많아질수록 `useReducer`가 구조를 정리하는 데 도움이 된다.

---

**2. 기본 구조**

```jsx
const [state, dispatch] = useReducer(reducer, initialState);
```

각 역할은 다음과 같다.

```text
state
→ 현재 State

dispatch
→ 상태 변경 요청 전달

reducer
→ 새로운 State 계산

initialState
→ 초기값
```

예:

```jsx
const [state, dispatch] = useReducer(reducer, 0);
```

---

**3. reducer 함수**

`reducer`는 현재 State와 Action을 받아 **새로운 State를 반환하는 함수**이다.

```jsx
function reducer(state, action) {
  switch (action.type) {
    case "INCREASE":
      return state + action.data;

    case "DECREASE":
      return state - action.data;

    default:
      return state;
  }
}
```

```text
현재 state
+
action
↓
reducer
↓
새로운 state
```

---

**4. Action**

Action은 **어떤 상태 변경이 발생했는지 전달하는 객체**이다.

```jsx
{
  type: "INCREASE",
  data: 1,
}
```

```text
type
→ 상태 변경 종류

data
→ 상태 변경에 필요한 값
```

현재 예제에서는 다음 두 종류를 사용한다.

```text
INCREASE
→ 증가

DECREASE
→ 감소
```

---

**5. dispatch**

`dispatch`는 Action을 전달해서 상태 변경을 요청한다.

```jsx
dispatch({
  type: "INCREASE",
  data: 1,
});
```

`dispatch`가 직접 State를 계산하는 것은 아니다.

```text
dispatch(action)
→ reducer(state, action)
→ 새로운 State 반환
→ State 변경
```

---

**6. 버튼 이벤트 처리**

증가:

```jsx
const onClickPlus = () => {
  dispatch({
    type: "INCREASE",
    data: 1,
  });
};
```

감소:

```jsx
const onClickMinus = () => {
  dispatch({
    type: "DECREASE",
    data: 1,
  });
};
```

전체 흐름은 같다.

```text
버튼 클릭
→ 이벤트 핸들러
→ dispatch(action)
→ reducer
→ 새로운 State
→ 리렌더링
```

---

**7. useState와 비교**

`useState`:

```jsx
setCount(count + 1);
```

```text
이벤트
→ setState()
→ State 변경
```

`useReducer`:

```jsx
dispatch({
  type: "INCREASE",
  data: 1,
});
```

```text
이벤트
→ dispatch(action)
→ reducer
→ State 변경
```

핵심 차이는 **상태 변경 규칙을 reducer에 모을 수 있다는 것**이다.

---

**8. reducer를 분리하는 이유**

`reducer`는 컴포넌트 밖에 둘 수 있다.

```jsx
function reducer(state, action) {
  // 상태 변경 로직
}

const Exam = () => {
  // 이벤트와 UI
};
```

```text
reducer
→ 상태 변경 규칙

컴포넌트
→ 이벤트 처리
→ UI 렌더링
```

상태 변경 로직이 복잡해질수록 컴포넌트의 역할을 단순하게 유지할 수 있다.

---

**9. 핵심 흐름**

`useReducer`에서 가장 중요하게 기억할 구조는 다음이다.

```text
이벤트
→ dispatch(action)
→ reducer(state, action)
→ 새로운 State 반환
→ 리렌더링
```

Action 중심으로 보면 다음과 같다.

```text
"무슨 일이 발생했는가?"
→ Action

"그럼 State를 어떻게 바꿀 것인가?"
→ reducer
```

---

**10. 핵심 정리**

* `useReducer`는 State를 관리하는 React Hook이다.
* 상태 변경 로직을 `reducer`로 분리할 수 있다.
* 기본 형태는 `const [state, dispatch] = useReducer(reducer, 초기값)`이다.
* `dispatch`는 Action을 전달한다.
* Action은 상태 변경에 필요한 정보를 담은 객체이다.
* `reducer`는 현재 State와 Action을 받아 새로운 State를 반환한다.
* `type`으로 상태 변경 종류를 구분할 수 있다.
* 상태 변경 종류가 많고 로직이 복잡할수록 `useReducer`가 유용하다.
* 핵심 흐름은 **`이벤트 → dispatch → reducer → 새로운 State → 리렌더링`**이다.
