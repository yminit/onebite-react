# Section 9 - 5. Read 투두리스트 렌더링하기

**1. 이번 단계의 핵심**

이번 단계에서는 `App`의 `todos` State를 `List`에 전달하고, 실제 Todo 데이터를 화면에 렌더링한다.

또한 검색어에 따라 목록을 필터링한다.

```text
todos State
→ Props
→ filter()
→ map()
→ TodoItem
```

---

**2. todos를 List에 전달하기**

전체 Todo 데이터는 `App`이 관리한다.

```jsx
<List todos={todos} />
```

```text
App
↓ todos
List
```

`List`에서는 Props로 받는다.

```jsx
const List = ({ todos }) => {
  // ...
};
```

---

**3. map()으로 Todo 반복 렌더링**

`todos`는 Todo 객체가 들어 있는 배열이다.

배열의 각 Todo를 `TodoItem`으로 렌더링할 때 `map()`을 사용한다.

```jsx
filteredTodos.map((todo) => {
  return <TodoItem key={todo.id} {...todo} />;
});
```

```text
Todo 배열
→ map()
→ TodoItem
→ TodoItem
→ TodoItem
```

Todo 데이터 개수만큼 `TodoItem`이 생성된다.

---

**4. Todo 데이터를 Props로 전달하기**

다음 코드는

```jsx
<TodoItem {...todo} />
```

개념적으로 다음과 같다.

```jsx
<TodoItem
  id={todo.id}
  isDone={todo.isDone}
  content={todo.content}
  date={todo.date}
/>
```

`TodoItem`에서는 필요한 값을 구조 분해 할당으로 받는다.

```jsx
const TodoItem = ({
  id,
  isDone,
  content,
  date,
}) => {
  // ...
};
```

---

**5. TodoItem 렌더링**

### a. 완료 여부

```jsx
<input
  type="checkbox"
  checked={isDone}
/>
```

현재 단계에서는 완료 상태를 **표시만 하고 수정 기능은 아직 구현하지 않는다.**

### b. Todo 내용

```jsx
<div className="content">
  {content}
</div>
```

### c. 날짜

```jsx
new Date(date).toLocaleDateString()
```

```text
timestamp
→ Date 객체
→ 날짜 문자열
→ 화면 표시
```

---

**6. key 사용하기**

배열을 `map()`으로 렌더링할 때 각 항목에 `key`를 지정한다.

```jsx
<TodoItem
  key={todo.id}
  {...todo}
/>
```

`key`는 React가 각 항목을 구분하는 데 사용한다.

따라서 Todo의 고유한 `id`를 사용하는 것이 적절하다.

---

**7. 검색어 State**

검색어는 `List`에서만 사용하므로 `List` 내부에서 관리한다.

```jsx
const [search, setSearch] = useState("");
```

```text
App
└─ todos
   → 전체 Todo 데이터

List
└─ search
   → 검색어
```

State를 실제 사용하는 컴포넌트 가까이에 두는 구조이다.

---

**8. 검색창과 State 연결**

```jsx
<input
  value={search}
  onChange={(e) => {
    setSearch(e.target.value);
  }}
/>
```

```text
사용자 검색
→ setSearch()
→ search 변경
→ List 리렌더링
```

---

**9. Todo 필터링**

검색어가 없으면 전체 Todo를 반환한다.

```text
search === ""
→ todos 전체 사용
```

검색어가 있으면 `filter()`를 사용한다.

```jsx
const getFilteredData = () => {
  if (search === "") {
    return todos;
  }

  return todos.filter((todo) =>
    todo.content
      .toLowerCase()
      .includes(search.toLowerCase())
  );
};
```

---

**10. filter(), includes(), toLowerCase()**

```text
filter()
→ 조건에 맞는 Todo 선택

includes()
→ 검색어 포함 여부 확인

toLowerCase()
→ 대소문자 차이 제거
```

예:

```text
"React 공부하기"
→ "react 공부하기"

검색어 "REACT"
→ "react"

includes("react")
→ true
```

---

**11. filteredTodos 렌더링**

```jsx
const filteredTodos = getFilteredData();
```

화면에서는 원본 `todos`가 아니라 검색 결과를 렌더링한다.

```jsx
filteredTodos.map((todo) => {
  return <TodoItem key={todo.id} {...todo} />;
});
```

```text
todos
→ filter()
→ filteredTodos
→ map()
→ TodoItem
```

---

**12. Create와 Read 연결**

이전 단계에서 Todo를 추가하면 `todos`가 변경된다.

```text
Editor
→ onCreate
→ todos 변경
```

그러면 새로운 `todos`가 다시 `List`에 전달된다.

```text
todos 변경
→ App 리렌더링
→ List에 새로운 todos 전달
→ List 리렌더링
→ TodoItem 목록 갱신
```

즉, **Create 결과가 Read 화면에 바로 반영된다.**

---

**13. 핵심 정리**

* 이번 단계는 CRUD의 `Read` 구현이다.
* `App`의 `todos`를 Props로 `List`에 전달한다.
* 배열 데이터는 `map()`으로 반복 렌더링한다.
* Todo 하나는 `TodoItem`이 담당한다.
* `{...todo}`로 Todo 객체를 Props로 전달할 수 있다.
* `key`에는 각 Todo를 구분하는 고유한 `id`를 사용한다.
* 검색어는 `List` 내부의 `search` State로 관리한다.
* `filter()`로 검색 조건에 맞는 Todo만 선택한다.
* `toLowerCase()`와 `includes()`로 대소문자와 관계없이 검색한다.
* 핵심 흐름은 **`todos → Props → filter → map → TodoItem`**이다.
