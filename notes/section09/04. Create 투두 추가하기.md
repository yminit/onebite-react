# Section 9 - 4. Create 투두 추가하기

**1. 이번 단계의 목표**

이번 단계에서는 CRUD 중 **Create**, 즉 새로운 Todo를 추가하는 기능을 구현한다.

```text id="cr01"
Editor에서 입력
→ 추가 요청
→ App의 onCreate 실행
→ 새 Todo 생성
→ todos State에 추가
```

---

**2. 역할 나누기**

`todos` State는 `App`이 관리하므로 실제 Todo 생성도 `App`에서 처리한다.

```text id="cr02"
Editor
→ 사용자 입력 관리
→ Todo 추가 요청

App
→ Todo 객체 생성
→ todos State 변경
```

`Editor`가 직접 `todos`를 수정하지 않고, `App`의 `onCreate`를 Props로 전달받아 호출한다.

---

**3. onCreate 함수**

```jsx id="cr03"
const onCreate = (content) => {
  const newTodo = {
    id: idRef.current++,
    isDone: false,
    content,
    date: new Date().getTime(),
  };

  setTodos([newTodo, ...todos]);
};
```

새 Todo도 앞에서 정의한 데이터 모델을 그대로 사용한다.

```text id="cr04"
id
→ Todo 식별값

isDone
→ 새 Todo이므로 false

content
→ 사용자가 입력한 내용

date
→ 생성 시점
```

---

**4. id는 useRef로 관리**

```jsx id="cr05"
const idRef = useRef(3);
```

새로운 Todo를 만들 때마다 값을 증가시킨다.

```jsx id="cr06"
id: idRef.current++
```

`id` 값 자체가 변경되어도 화면을 다시 렌더링할 필요는 없으므로 State가 아니라 Ref를 사용한다.

---

**5. 새로운 Todo를 배열에 추가**

```jsx id="cr07"
setTodos([newTodo, ...todos]);
```

기존 배열을 직접 수정하지 않고 새로운 배열을 만든다.

```text id="cr08"
newTodo
+
...todos

→ 새로운 todos 배열
```

새 Todo를 배열 앞에 추가하기 때문에 최신 Todo가 먼저 위치한다.

---

**6. onCreate를 Editor에 전달**

`App`:

```jsx id="cr09"
<Editor onCreate={onCreate} />
```

`Editor`:

```jsx id="cr10"
const Editor = ({ onCreate }) => {
  // ...
};
```

```text id="cr11"
App
↓ onCreate Props
Editor
```

---

**7. Editor의 입력값 관리**

`Editor`에서만 필요한 입력값은 `Editor` 내부 State로 관리한다.

```jsx id="cr12"
const [content, setContent] = useState("");
```

```jsx id="cr13"
<input
  value={content}
  onChange={(e) => {
    setContent(e.target.value);
  }}
/>
```

```text id="cr14"
사용자 입력
→ setContent()
→ content State 변경
```

`todos`는 여러 컴포넌트에서 사용하므로 `App`에 두고, `content`는 `Editor`만 사용하므로 `Editor`에 둔다.

---

**8. Todo 추가 처리**

추가 버튼을 누르면 `onSubmit`을 실행한다.

```jsx id="cr15"
const onSubmit = () => {
  if (content === "") {
    contentRef.current.focus();
    return;
  }

  onCreate(content);
  setContent("");
};
```

전체 흐름:

```text id="cr16"
추가 버튼 클릭
→ 입력값 확인
→ 비어 있으면 focus 후 종료
→ 값이 있으면 onCreate(content)
→ Todo 추가
→ 입력창 초기화
```

---

**9. input에 포커스하기**

빈 Todo 입력을 막기 위해 `useRef`로 input DOM을 참조한다.

```jsx id="cr17"
const contentRef = useRef();
```

```jsx id="cr18"
<input ref={contentRef} />
```

```jsx id="cr19"
contentRef.current.focus();
```

이 부분은 앞에서 배운 **DOM 요소 참조용 useRef** 활용이다.

---

**10. 전체 데이터 흐름**

```text id="cr20"
사용자 입력
→ content State
→ onSubmit()
→ onCreate(content)
→ App에서 newTodo 생성
→ setTodos()
→ todos State 변경
```

핵심은 **입력은 Editor가 관리하고, 실제 Todo 데이터는 App이 관리한다**는 점이다.

---

**11. 핵심 정리**

* 이번 단계는 CRUD의 `Create` 구현이다.
* `todos` State와 `onCreate`는 `App`에서 관리한다.
* `Editor`는 입력값 `content`를 자신의 State로 관리한다.
* `onCreate`는 Props로 `Editor`에 전달한다.
* 새 Todo는 기존 데이터 모델과 같은 구조로 만든다.
* `id`는 리렌더링이 필요 없는 값이므로 `useRef`로 관리한다.
* 배열 State는 직접 수정하지 않고 새로운 배열로 변경한다.
* 빈 입력이면 Todo를 추가하지 않고 input에 포커스를 준다.
* 추가가 끝나면 `setContent("")`로 입력창을 초기화한다.
* 핵심 흐름은 **Editor 입력 → onCreate 전달 → App에서 Todo 생성 → todos State 변경**이다.
