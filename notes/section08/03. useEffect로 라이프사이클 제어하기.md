# Section 8 - 3. useEffect로 라이프사이클 제어하기

**1. 라이프사이클과 useEffect**

React 컴포넌트의 라이프사이클은 다음 3단계로 나눌 수 있다.

```text
Mount
→ Update
→ UnMount
```

`useEffect`를 이용하면 각 시점에 필요한 작업을 처리할 수 있다.

---

**2. Mount 처리하기**

빈 의존성 배열 `[]`을 사용하면 컴포넌트가 처음 렌더링된 뒤 Effect가 실행된다.

```jsx
useEffect(() => {
  console.log("mount");
}, []);
```

```text
최초 렌더링
→ Mount
→ useEffect 실행
```

---

**3. Update 처리하기**

의존성 배열을 생략하면 렌더링 이후마다 Effect가 실행된다.

```jsx
useEffect(() => {
  console.log("update");
});
```

하지만 최초 Mount 때도 실행되므로, 이번 실습에서는 `useRef`로 첫 실행을 제외한다.

```jsx
const isMount = useRef(false);

useEffect(() => {
  if (!isMount.current) {
    isMount.current = true;
    return;
  }

  console.log("update");
});
```

```text
첫 실행
→ 건너뜀

이후 리렌더링
→ "update"
```

---

**4. UnMount 처리하기**

`useEffect`에서 반환하는 함수를 **Cleanup 함수**라고 한다.

```jsx
useEffect(() => {
  return () => {
    console.log("unmount");
  };
}, []);
```

컴포넌트가 화면에서 제거될 때 Cleanup 함수가 실행된다.

---

**5. 조건부 렌더링으로 UnMount 확인하기**

```jsx
{count % 2 === 0 ? <Even /> : null}
```

```text
count가 짝수
→ Even 렌더링

count가 홀수
→ Even 제거
→ UnMount
→ Cleanup 실행
```

`Even` 컴포넌트:

```jsx
import { useEffect } from "react";

const Even = () => {
  useEffect(() => {
    return () => {
      console.log("unmount");
    };
  }, []);

  return <div>EVEN</div>;
};

export default Even;
```

조건에 따라 컴포넌트는 Mount와 UnMount를 반복할 수 있다.

---

**6. 라이프사이클별 정리**

```text
Mount
→ useEffect(..., [])

Update
→ useEffect(...)
→ 이번 실습에서는 첫 실행을 useRef로 제외

UnMount
→ useEffect의 Cleanup 함수
```

---

**7. 핵심 정리**

* `Mount`는 컴포넌트가 처음 화면에 나타나는 시점이다.
* `useEffect(..., [])`로 Mount 이후 작업을 처리할 수 있다.
* `Update`는 컴포넌트가 리렌더링되는 시점이다.
* 의존성 배열을 생략한 Effect는 렌더링 이후마다 실행된다.
* 최초 실행을 제외해야 한다면 `useRef`를 활용할 수 있다.
* `useEffect`가 반환하는 함수는 Cleanup 함수이다.
* Cleanup 함수는 UnMount 시점의 정리 작업에 사용할 수 있다.
* `useEffect`를 이용하면 컴포넌트 라이프사이클에 맞춰 필요한 작업을 처리할 수 있다.
