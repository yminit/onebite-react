# Section 8 - 4. React 개발자 도구 사용하기

**1. React Developer Tools란?**

React 애플리케이션을 **확인하고 디버깅하기 위한 브라우저 확장 프로그램**이다.

```text
React App
→ React Developer Tools
→ 컴포넌트 구조와 상태 확인
```

---

**2. 설치하기**

Chrome을 사용하는 경우 Chrome 웹 스토어에서 다음 확장 프로그램을 설치한다.

```text
React Developer Tools
```

설치 후 확장 프로그램이 활성화되어 있는지 확인한다.

---

**3. 사용하기**

React 프로젝트를 실행한 상태에서 브라우저 개발자 도구를 연다.

React Developer Tools를 통해 React 컴포넌트 구조를 확인할 수 있다.

예를 들어 Counter App은 다음처럼 확인할 수 있다.

```text
App
├─ Viewer
├─ Even
└─ Controller
```

---

**4. 무엇을 확인할 수 있나?**

React 개발 과정에서 주로 다음 내용을 확인하고 디버깅할 때 사용한다.

```text
컴포넌트 구조
Props
State
컴포넌트 렌더링 상태
```

코드만 보는 것보다 실제 실행 중인 컴포넌트 구조와 데이터를 확인하기 쉽다.

---

**5. 핵심 정리**

* React Developer Tools는 React 전용 디버깅 도구이다.
* 브라우저 확장 프로그램으로 설치해서 사용한다.
* React 프로젝트 실행 후 개발자 도구에서 확인할 수 있다.
* 컴포넌트 계층 구조와 Props, State 등을 확인하는 데 유용하다.
* 앞으로 React 애플리케이션의 동작이나 렌더링 문제를 확인할 때 자주 활용한다.
