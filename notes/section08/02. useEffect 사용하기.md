# Section 8 - 2. useEffect 사용하기

**1. useEffect란?**

`useEffect`는 컴포넌트의 렌더링 이후에 필요한 **사이드 이펙트(Side Effect)**를 처리하는 Hook이다.

```jsx id="ue801"
useEffect(() => {
  console.log(`count: ${count} / input: ${input}`);
}, [count, input]);
```

---

**2. 사이드 이펙트**

사이드 이펙트는 렌더링 자체가 아니라, 그 이후에 추가로 수행해야 하는 작업을 의미한다.

현재 예제에서는 다음 작업이 해당한다.

```text id="ue802"
count 또는 input 변경
→ 컴포넌트 리렌더링
→ useEffect 실행
→ console.log()
```

---

**3. useEffect 기본 형태**

```jsx id="ue803"
useEffect(() => {
  // 실행할 작업
}, [의존성]);
```

두 부분으로 구성된다.

```text id="ue804"
첫 번째 인수
→ 실행할 함수

두 번째 인수
→ 의존성 배열
```

---

**4. 의존성 배열**

두 번째 인수의 배열을 **Dependency Array**, 줄여서 `deps`라고 한다.

```jsx id="ue805"
[count, input]
```

현재 Effect는 `count`와 `input`에 의존한다.

```text id="ue806"
count 변경
→ Effect 실행

input 변경
→ Effect 실행
```

둘 중 하나라도 값이 달라지면 해당 Effect가 다시 실행된다.

---

**5. 실행 흐름**

예를 들어 `count`가 변경되면 다음과 같이 동작한다.

```text id="ue807"
버튼 클릭
→ setCount()
→ count 변경
→ App 리렌더링
→ useEffect 실행
```

`input`도 같은 원리이다.

```text id="ue808"
사용자 입력
→ setInput()
→ input 변경
→ App 리렌더링
→ useEffect 실행
```

---

**6. 현재 예제**

```jsx id="ue809"
import { useEffect, useState } from "react";

function App() {
  const [count, setCount] = useState(0);
  const [input, setInput] = useState("");

  useEffect(() => {
    console.log(`count: ${count} / input: ${input}`);
  }, [count, input]);

  return (
    <input
      value={input}
      onChange={(e) => {
        setInput(e.target.value);
      }}
    />
  );
}
```

핵심은 State를 변경하는 것과 Effect에서 추가 작업을 처리하는 것을 분리하는 것이다.

---

**7. 핵심 정리**

* `useEffect`는 렌더링 이후 필요한 사이드 이펙트를 처리한다.
* 첫 번째 인수에는 실행할 함수를 전달한다.
* 두 번째 인수는 의존성 배열이다.
* `[count, input]`이라면 두 값 중 하나가 변경될 때 Effect가 실행된다.
* `useEffect`는 State를 변경하는 기능이 아니라, **변화 이후 필요한 작업을 처리하는 기능**으로 이해하면 된다.
