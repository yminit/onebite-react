# Section 8 - 1. 라이프사이클이란?

**1. 컴포넌트 라이프사이클**

React 컴포넌트에는 생성되고, 변경되고, 사라지는 흐름이 있다.

크게 3단계로 나눈다.

```text
Mount
→ Update
→ UnMount
```

---

**2. Mount**

`Mount`는 컴포넌트가 **처음 화면에 나타나는 시점**이다.

```text
컴포넌트 생성
→ 최초 렌더링
→ Mount
```

---

**3. Update**

`Update`는 컴포넌트가 **다시 렌더링되는 시점**이다.

State나 Props 등의 변화로 리렌더링이 발생할 수 있다.

```text
값 변경
→ 리렌더링
→ Update
```

하나의 컴포넌트는 Mount된 뒤 여러 번 Update될 수 있다.

---

**4. UnMount**

`UnMount`는 컴포넌트가 **화면에서 제거되는 시점**이다.

```text
화면에 있던 컴포넌트
→ 렌더링에서 제외
→ UnMount
```

---

**5. 전체 흐름**

```text
컴포넌트 생성
→ Mount
→ 화면 표시
→ Update
→ Update
→ ...
→ UnMount
→ 화면에서 제거
```

---

**6. 라이프사이클을 알아야 하는 이유**

각 시점에 맞는 작업을 처리하기 위해 필요하다.

```text
Mount
→ 처음 나타났을 때 필요한 작업

Update
→ 값이 변경된 뒤 필요한 작업

UnMount
→ 사라지기 전에 필요한 정리 작업
```

이후 배우게 될 `useEffect`를 이해할 때 중요한 기반이 된다.

---

**7. 핵심 정리**

* React 컴포넌트의 라이프사이클은 `Mount`, `Update`, `UnMount`로 나눌 수 있다.
* `Mount`는 처음 화면에 나타나는 시점이다.
* `Update`는 컴포넌트가 다시 렌더링되는 시점이다.
* `UnMount`는 컴포넌트가 화면에서 제거되는 시점이다.
* 컴포넌트는 Mount 후 여러 번 Update될 수 있다.
* 라이프사이클을 이해하면 각 시점에 필요한 작업을 처리할 수 있다.
