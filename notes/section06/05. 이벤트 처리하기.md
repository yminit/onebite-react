# Section 6 - 5. 이벤트 처리하기

**1. 이벤트와 이벤트 핸들러**

이벤트는 사용자의 행동으로 발생하는 동작이다.

```text
클릭
마우스 이동
입력
키보드 입력
```

이벤트가 발생했을 때 실행할 함수를 **이벤트 핸들러**라고 한다.

```jsx
const onClickButton = () => {
  console.log("버튼 클릭");
};

<button onClick={onClickButton}>버튼</button>
```

---

**2. 이벤트 핸들러는 함수 자체를 전달**

이벤트 핸들러는 실행 결과가 아니라 **함수 자체를 전달**해야 한다.

```jsx
<button onClick={onClickButton}>버튼</button>
```

다음처럼 호출하면 렌더링 과정에서 바로 실행된다.

```jsx
<button onClick={onClickButton()}>버튼</button>
```

```text
onClick={onClickButton}
→ 함수 전달

onClick={onClickButton()}
→ 함수 즉시 실행
```

---

**3. React 이벤트 이름**

React 이벤트 속성은 camelCase로 작성한다.

```jsx
onClick
onMouseEnter
```

예:

```jsx
<button
  onClick={onClickButton}
  onMouseEnter={onClickButton}
>
  버튼
</button>
```

---

**4. 이벤트 객체**

이벤트가 발생하면 React가 이벤트 정보를 이벤트 핸들러에 전달한다.

```jsx
const onClickButton = (e) => {
  console.log(e);
};
```

`e`에는 발생한 이벤트에 대한 정보가 들어 있다.

```text
이벤트 발생
→ 이벤트 객체 전달
→ 이벤트 핸들러 실행
```

---

**5. Props와 이벤트 함께 사용하기**

이벤트 핸들러에서는 컴포넌트가 전달받은 Props도 사용할 수 있다.

```jsx
const Button = ({ text }) => {
  const onClickButton = (e) => {
    console.log(e);
    console.log(text);
  };

  return (
    <button onClick={onClickButton}>
      {text}
    </button>
  );
};
```

부모에서 전달한 값에 따라 각 버튼이 다른 데이터를 사용할 수 있다.

```jsx
<Button text="메일" />
<Button text="카페" />
<Button text="블로그" />
```

---

**6. Synthetic Event**

React는 브라우저 이벤트를 **Synthetic Event(합성 이벤트)** 형태로 제공한다.

```text
브라우저 이벤트
→ React
→ Synthetic Event
→ 이벤트 핸들러
```

브라우저별 이벤트 차이를 React에서 일정한 방식으로 다룰 수 있도록 해준다.

---

**7. 핵심 정리**

* 이벤트는 클릭, 입력 등 사용자의 행동으로 발생한다.
* 이벤트 핸들러는 이벤트를 처리하는 함수이다.
* React에서는 `onClick`, `onMouseEnter`처럼 camelCase로 이벤트를 등록한다.
* 이벤트 핸들러에는 함수를 실행하지 않고 함수 자체를 전달한다.
* 이벤트가 발생하면 이벤트 객체를 전달받을 수 있다.
* 이벤트 핸들러 안에서 Props도 사용할 수 있다.
* React는 이벤트를 Synthetic Event 형태로 제공한다.
