# Section 6 - 9. State로 사용자 입력 관리하기 2

**1. 여러 입력값을 객체 State로 관리하기**

입력값이 많아지면 State와 이벤트 핸들러를 각각 만드는 방식은 코드가 길어진다.

따라서 관련된 입력값을 하나의 객체 State로 묶어 관리할 수 있다.

```jsx
const [input, setInput] = useState({
  name: "",
  birth: "",
  country: "",
  bio: "",
});
```

각 값은 객체의 프로퍼티로 접근한다.

```jsx
input.name;
input.birth;
input.country;
input.bio;
```

---

**2. 하나의 onChange 사용하기**

모든 입력 요소에서 같은 이벤트 핸들러를 사용할 수 있다.

```jsx
const onChange = (e) => {
  setInput({
    ...input,
    [e.target.name]: e.target.value,
  });
};
```

각 입력 요소에는 State 프로퍼티와 같은 `name`을 지정한다.

```jsx
<input
  name="name"
  value={input.name}
  onChange={onChange}
/>

<input
  name="birth"
  value={input.birth}
  onChange={onChange}
/>
```

---

**3. e.target.name과 value**

이벤트 객체를 이용하면 두 가지 정보를 얻을 수 있다.

```text
e.target.name
→ 어떤 입력값을 변경할지 결정

e.target.value
→ 새로 입력된 값
```

예를 들어 이름에 `"홍길동"`을 입력하면 다음과 같다.

```text
e.target.name  → "name"
e.target.value → "홍길동"
```

---

**4. 계산된 프로퍼티**

다음 문법을 사용하면 변경할 프로퍼티를 동적으로 결정할 수 있다.

```jsx
[e.target.name]: e.target.value
```

예:

```text
name="name"
value="홍길동"

↓

name: "홍길동"
```

따라서 여러 입력 요소가 하나의 `onChange`를 공유할 수 있다.

---

**5. Spread를 사용하는 이유**

객체 State를 변경할 때 기존 객체를 직접 수정하지 않고 새로운 객체를 만든다.

```jsx
setInput({
  ...input,
  [e.target.name]: e.target.value,
});
```

```text
...input
→ 기존 값 복사

[e.target.name]
→ 변경할 값만 덮어쓰기

→ 새로운 객체 생성
```

예를 들어 `name`만 변경하면 `birth`, `country`, `bio`는 기존 값을 유지한다.

---

**6. 전체 입력 처리 흐름**

```text
사용자 입력
→ onChange 발생
→ e.target.name 확인
→ 변경할 프로퍼티 결정
→ e.target.value 확인
→ 기존 객체 복사
→ 해당 값만 변경
→ setInput()
→ 리렌더링
```

이 흐름이 모든 입력 요소에서 동일하게 사용된다.

---

**7. 핵심 정리**

* 관련된 여러 입력값을 하나의 객체 State로 관리할 수 있다.
* 입력 요소의 `name`은 State 객체의 프로퍼티 이름과 맞춘다.
* `e.target.name`으로 변경할 프로퍼티를 찾는다.
* `e.target.value`로 새로운 입력값을 가져온다.
* `[e.target.name]`으로 프로퍼티를 동적으로 지정한다.
* `...input`으로 기존 값을 유지하면서 필요한 값만 변경한다.
* 하나의 `onChange`를 여러 입력 요소에서 재사용할 수 있다.
* 객체 State는 직접 수정하지 않고 새로운 객체를 만들어 변경한다.
