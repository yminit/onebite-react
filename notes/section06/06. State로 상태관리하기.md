# Section 6 - 6. State로 상태 관리하기

**1. State란?**

State는 컴포넌트가 가지고 있는 **변경 가능한 상태값**이다.

```text
State 변경
→ 컴포넌트 리렌더링
→ 변경된 UI 표시
```

화면에 영향을 주고 시간이 지나면서 값이 바뀌는 데이터는 State로 관리한다.

---

**2. useState 사용하기**

React에서는 `useState`로 State를 만든다.

```jsx
import { useState } from "react";

const [count, setCount] = useState(0);
```

기본 형태:

```jsx
const [state, setState] = useState(초기값);
```

```text
count
→ 현재 State 값

setCount
→ State를 변경하는 함수

0
→ 초기값
```

하나의 컴포넌트에서 여러 State를 사용할 수도 있다.

```jsx
const [count, setCount] = useState(0);
const [light, setLight] = useState("OFF");
```

---

**3. State 변경하기**

상태 변화 함수를 호출해서 State를 변경한다.

```jsx
setCount(count + 1);
```

예:

```jsx
<button
  onClick={() => {
    setCount(count + 1);
  }}
>
  +
</button>
```

```text
버튼 클릭
→ setCount()
→ count 변경
→ 리렌더링
```

---

**4. State에 따라 UI 변경하기**

State 값은 JSX에서 사용할 수 있다.

```jsx
<h1>{light}</h1>
```

조건부 렌더링과 함께 사용할 수도 있다.

```jsx
<button
  onClick={() => {
    setLight(light === "ON" ? "OFF" : "ON");
  }}
>
  {light === "ON" ? "끄기" : "켜기"}
</button>
```

```text
OFF → [켜기]
ON  → [끄기]
```

---

**5. 리렌더링**

State가 변경되면 React는 컴포넌트를 다시 렌더링한다.

함수 컴포넌트에서는 컴포넌트 함수가 다시 실행되고 새로운 State를 기준으로 JSX를 다시 만든다.

```text
State 변경
→ 컴포넌트 함수 다시 실행
→ 새로운 JSX 계산
→ 화면 업데이트
```

---

**6. 일반 변수와 State 차이**

일반 변수의 값만 변경하면 React는 자동으로 리렌더링하지 않는다.

```jsx
let count = 0;

count = count + 1;
```

반면 State는 상태 변화 함수를 통해 변경하면 React가 리렌더링한다.

```jsx
setCount(count + 1);
```

따라서 **값의 변경이 화면에도 반영되어야 한다면 State를 사용한다.**

---

**7. 핵심 정리**

* State는 컴포넌트의 변경 가능한 상태값이다.
* `useState()`로 State를 생성한다.
* `useState()`는 현재 값과 상태 변화 함수를 반환한다.
* 하나의 컴포넌트에서 여러 State를 사용할 수 있다.
* State 값은 JSX에서 사용할 수 있다.
* State가 변경되면 컴포넌트가 리렌더링된다.
* 리렌더링 시 함수 컴포넌트가 다시 실행된다.
* 일반 변수 변경만으로는 React가 자동으로 리렌더링하지 않는다.
* 화면에 영향을 주는 동적인 값은 State로 관리한다.
