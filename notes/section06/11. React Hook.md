# Section 6 - 11. React Hook

**1. React Hook이란?**

React Hook은 **함수 컴포넌트에서 State, Ref 같은 React 기능을 사용할 수 있게 해주는 기능**이다.

지금까지 사용한 `useState`, `useRef`도 모두 Hook이다.

```text
React Hook
├─ useState
├─ useRef
└─ Custom Hook
```

---

**2. Hook 이름 규칙**

Hook 이름은 일반적으로 `use`로 시작한다.

```text
useState
useRef
useInput
```

직접 만드는 Custom Hook도 같은 규칙을 따른다.

---

**3. Hook 사용 규칙**

Hook은 다음 규칙을 지켜서 사용한다.

```text
1. 함수 컴포넌트 또는 Custom Hook 안에서 호출
2. 조건문이나 반복문 안에서 호출하지 않음
3. 항상 같은 순서로 호출되도록 작성
```

보통 컴포넌트 최상위에서 호출한다.

```jsx
const HookExam = () => {
  const [input, onChange] = useInput();

  return <div></div>;
};
```

조건문이나 반복문 안에서 Hook을 호출하면 렌더링마다 호출 순서가 달라질 수 있기 때문에 사용하지 않는다.

---

**4. Custom Hook**

반복되는 React 로직은 직접 Hook으로 만들어 재사용할 수 있다.

이를 **Custom Hook**이라고 한다.

예를 들어 입력값 관리 로직을 `useInput`으로 분리할 수 있다.

```jsx
import { useState } from "react";

function useInput() {
  const [input, setInput] = useState("");

  const onChange = (e) => {
    setInput(e.target.value);
  };

  return [input, onChange];
}

export default useInput;
```

---

**5. Custom Hook 사용하기**

컴포넌트에서는 일반 Hook처럼 호출한다.

```jsx
import useInput from "../hooks/useInput";

const HookExam = () => {
  const [input, onChange] = useInput();

  return (
    <input
      value={input}
      onChange={onChange}
      type="text"
    />
  );
};
```

동작 흐름:

```text
사용자 입력
→ onChange
→ setInput()
→ State 변경
→ 리렌더링
→ 새로운 입력값 표시
```

---

**6. Custom Hook을 사용하는 이유**

컴포넌트마다 다음 로직을 반복하지 않고

```jsx
const [input, setInput] = useState("");

const onChange = (e) => {
  setInput(e.target.value);
};
```

Custom Hook으로 분리해서 재사용할 수 있다.

```jsx
const [input, onChange] = useInput();
```

```text
반복되는 React 로직
→ Custom Hook으로 분리
→ 여러 컴포넌트에서 재사용
```

---

**7. 핵심 정리**

* `useState`, `useRef`는 React Hook이다.
* Hook은 함수 컴포넌트나 Custom Hook에서 사용한다.
* Hook 이름은 `use`로 시작한다.
* Hook은 조건문이나 반복문 안에서 호출하지 않는다.
* Hook은 렌더링마다 같은 순서로 호출되어야 한다.
* 반복되는 React 로직은 Custom Hook으로 분리할 수 있다.
* Custom Hook 내부에서도 다른 Hook을 사용할 수 있다.
* `useInput`처럼 State와 관련 로직을 함께 묶어 재사용할 수 있다.
