# Section 6 - 8. State로 사용자 입력 1

**1. 입력값을 State로 관리하기**

React에서는 입력 요소의 값을 State와 연결해서 관리할 수 있다.

이번 예시는 다음 입력값을 각각 State로 관리한다.

```text
이름
생년월일
국적
자기소개
```

```jsx
const [name, setName] = useState("");
const [birth, setBirth] = useState("");
const [country, setCountry] = useState("");
const [bio, setBio] = useState("");
```

---

**2. value와 onChange**

입력 요소를 State와 연결할 때 핵심은 `value`와 `onChange`이다.

```jsx
<input
  value={name}
  onChange={onChangeName}
/>
```

```text
value
→ 현재 State 값을 화면에 표시

onChange
→ 사용자가 입력한 값을 State에 저장
```

---

**3. e.target.value**

입력값이 변경되면 이벤트 객체를 통해 현재 값을 가져올 수 있다.

```jsx
const onChangeName = (e) => {
  setName(e.target.value);
};
```

```text
e
→ 이벤트 객체

e.target
→ 이벤트가 발생한 요소

e.target.value
→ 현재 입력된 값
```

전체 흐름:

```text
사용자 입력
→ onChange 발생
→ e.target.value 확인
→ State 변경
→ 리렌더링
→ 변경된 값 표시
```

---

**4. 여러 입력 요소 관리**

`input`, `select`, `textarea` 모두 같은 방식으로 State와 연결할 수 있다.

### a. input

```jsx
<input
  value={birth}
  onChange={(e) => setBirth(e.target.value)}
  type="date"
/>
```

### b. select

```jsx
<select
  value={country}
  onChange={(e) => setCountry(e.target.value)}
>
  <option value=""></option>
  <option value="kr">한국</option>
  <option value="us">미국</option>
  <option value="uk">영국</option>
</select>
```

### c. textarea

```jsx
<textarea
  value={bio}
  onChange={(e) => setBio(e.target.value)}
/>
```

---

**5. 핵심 구조**

현재 단계에서는 입력값마다 State와 이벤트 핸들러를 각각 만든다.

```text
name
→ setName()

birth
→ setBirth()

country
→ setCountry()

bio
→ setBio()
```

모두 동작 원리는 동일하다.

```text
State
→ value
→ 사용자 입력
→ onChange
→ State 변경
→ 리렌더링
```

---

**6. 핵심 정리**

* React에서는 사용자 입력값을 State로 관리할 수 있다.
* `value`에는 현재 State 값을 전달한다.
* `onChange`는 입력값이 변경될 때 실행된다.
* `e.target.value`로 현재 입력값을 가져온다.
* 상태 변화 함수로 입력값을 State에 저장한다.
* State가 변경되면 컴포넌트가 리렌더링된다.
* `input`, `select`, `textarea` 모두 같은 방식으로 State와 연결할 수 있다.
