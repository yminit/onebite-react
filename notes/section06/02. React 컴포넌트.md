# Section 6 - 2. React 컴포넌트

**1. 컴포넌트란?**

컴포넌트는 React에서 **UI를 구성하는 기본 단위**이다.

현재 단계에서는 JSX 형태의 UI를 반환하는 함수라고 이해하면 된다.

```jsx id="react621"
function Header() {
  return <header>헤더</header>;
}
```

---

**2. 컴포넌트 이름 규칙**

React 컴포넌트 이름은 **대문자로 시작**해야 한다.

```jsx id="react622"
<Header />
<Main />
<Footer />
```

```text id="react623"
소문자 시작
→ HTML 태그

대문자 시작
→ React 컴포넌트
```

---

**3. 컴포넌트 파일 분리**

컴포넌트는 역할별로 파일을 나누어 관리할 수 있다.

```text id="react624"
src/
├─ components/
│  ├─ Header.jsx
│  ├─ Main.jsx
│  └─ Footer.jsx
├─ App.jsx
└─ main.jsx
```

예시:

```jsx id="react625"
function Header() {
  return <header>헤더</header>;
}

export default Header;
```

---

**4. 컴포넌트 조합하기**

다른 파일의 컴포넌트를 `import`한 뒤 태그처럼 사용한다.

```jsx id="react626"
import Header from "./components/Header";
import Main from "./components/Main";
import Footer from "./components/Footer";

function App() {
  return (
    <div>
      <Header />
      <Main />
      <Footer />
    </div>
  );
}

export default App;
```

작은 컴포넌트들을 조합해서 하나의 화면을 만든다.

---

**5. 부모와 자식 컴포넌트**

다른 컴포넌트를 포함하는 컴포넌트를 **부모**, 포함되는 컴포넌트를 **자식**이라고 한다.

```text id="react627"
App
├─ Header
├─ Main
└─ Footer
```

여기서는 `App`이 부모이고 `Header`, `Main`, `Footer`가 자식이다.

---

**6. Root Component**

컴포넌트 구조의 가장 위에 있는 컴포넌트를 **Root Component**라고 한다.

현재 프로젝트에서는 `main.jsx`에서 `App`을 처음 렌더링한다.

```jsx id="react628"
createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>
);
```

따라서 현재 구조에서는 `App`이 Root Component 역할을 한다.

```text id="react629"
main.jsx
→ App
   ├─ Header
   ├─ Main
   └─ Footer
```

---

**7. 핵심 정리**

* 컴포넌트는 React UI의 기본 단위이다.
* 컴포넌트 이름은 대문자로 시작한다.
* 컴포넌트는 `<Header />`처럼 태그 형태로 사용한다.
* 컴포넌트는 역할별로 파일을 분리해서 관리할 수 있다.
* 부모 컴포넌트는 자식 컴포넌트를 포함한다.
* 작은 컴포넌트를 조합해 하나의 화면을 만든다.
* 현재 프로젝트에서는 `App`이 Root Component 역할을 한다.
