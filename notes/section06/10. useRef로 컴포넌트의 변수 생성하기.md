# Section 6 - 10. useRef로 컴포넌트의 변수 생성하기

**1. useRef란?**

`useRef`는 값을 저장할 수 있는 **Reference 객체**를 만든다.

```jsx
const countRef = useRef(0);
```

생성된 객체는 다음처럼 `current`에 값을 저장한다.

```text
countRef
└─ current: 0
```

값을 읽거나 변경할 때도 `current`를 사용한다.

```jsx
countRef.current;
countRef.current++;
```

---

**2. useRef의 핵심 특징**

`ref.current`를 변경해도 **리렌더링이 발생하지 않는다.**

```text
State 변경
→ 리렌더링 O

Ref 변경
→ 리렌더링 X
```

또한 컴포넌트가 리렌더링되어도 Ref에 저장된 값은 유지된다.

---

**3. 일반 변수와의 차이**

컴포넌트 내부의 일반 변수는 리렌더링으로 함수가 다시 실행되면 다시 초기화될 수 있다.

```jsx
let count = 0;
```

반면 `useRef`의 값은 렌더링 사이에서도 유지된다.

```jsx
const countRef = useRef(0);
```

따라서 **화면을 다시 그릴 필요는 없지만 계속 기억해야 하는 값**에 사용할 수 있다.

---

**4. 입력 횟수 저장하기**

입력할 때마다 Ref 값을 증가시킬 수 있다.

```jsx
const countRef = useRef(0);

const onChange = (e) => {
  countRef.current++;

  setInput({
    ...input,
    [e.target.name]: e.target.value,
  });
};
```

`setInput()` 때문에 컴포넌트가 리렌더링되어도 `countRef.current` 값은 유지된다.

---

**5. DOM 요소 참조하기**

`useRef`는 실제 DOM 요소에 접근할 때도 사용한다.

```jsx
const inputRef = useRef();

<input ref={inputRef} />
```

React가 해당 DOM 요소를 `inputRef.current`에 연결한다.

```text
inputRef.current
→ 실제 input DOM 요소
```

---

**6. DOM 요소 조작하기**

예를 들어 이름이 비어 있을 때 입력창으로 포커스를 이동할 수 있다.

```jsx
const onSubmit = () => {
  if (input.name === "") {
    inputRef.current.focus();
  }
};
```

```text
제출
→ 이름 확인
→ 비어 있음
→ inputRef.current.focus()
→ 입력창에 포커스
```

---

**7. State와 useRef 사용 기준**

```text
State
→ 값이 화면에 표시됨
→ 값이 바뀌면 UI도 변경되어야 함

useRef
→ 렌더링 사이에서 값을 기억
→ 값 변경만으로 리렌더링할 필요 없음
→ DOM 요소에 접근할 때 사용
```

현재 실습에서는 다음처럼 구분한다.

```text
input
→ State
→ 사용자 입력값

countRef
→ Ref
→ 입력 횟수

inputRef
→ Ref
→ input DOM 요소
```

---

**8. 핵심 정리**

* `useRef()`는 `current` 프로퍼티를 가진 객체를 반환한다.
* `ref.current`로 값을 읽고 변경한다.
* Ref 값 변경 자체는 리렌더링을 발생시키지 않는다.
* 컴포넌트가 리렌더링되어도 Ref 값은 유지된다.
* 화면에 반영되어야 하는 값은 State로 관리한다.
* 리렌더링 없이 기억할 값은 Ref를 활용할 수 있다.
* `ref` 속성과 `useRef`를 연결하면 실제 DOM 요소에 접근할 수 있다.
* `inputRef.current.focus()`처럼 DOM 기능을 사용할 수도 있다.
