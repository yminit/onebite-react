# Section 6 - 4. Props로 데이터 전달하기

**1. Props란?**

Props는 **부모 컴포넌트가 자식 컴포넌트에게 데이터를 전달하는 방법**이다.

같은 컴포넌트를 재사용하면서 값만 다르게 전달할 수 있다.

```jsx
<Button text="메일" />
<Button text="카페" />
```

---

**2. Props 전달하기**

부모 컴포넌트에서 속성처럼 값을 전달한다.

```jsx
<Button text="메일" color="red" />
```

자식 컴포넌트에서는 `props` 객체로 받는다.

```jsx
const Button = (props) => {
  return <button>{props.text}</button>;
};
```

---

**3. 구조 분해 할당**

Props는 객체이므로 구조 분해 할당을 자주 사용한다.

```jsx
const Button = ({ text, color }) => {
  return (
    <button style={{ color }}>
      {text}
    </button>
  );
};
```

기본값도 지정할 수 있다.

```jsx
const Button = ({ text, color = "black" }) => {
  return <button style={{ color }}>{text}</button>;
};
```

---

**4. Spread로 Props 전달하기**

여러 Props를 객체에 담아 한 번에 전달할 수 있다.

```jsx
const buttonProps = {
  text: "메일",
  color: "red",
};

<Button {...buttonProps} />
```

다음과 같은 의미이다.

```jsx
<Button text="메일" color="red" />
```

---

**5. children**

컴포넌트 태그 사이에 작성한 내용은 `children` Props로 전달된다.

```jsx
<Button text="블로그">
  <div>자식 요소</div>
</Button>
```

자식 컴포넌트에서 사용할 수 있다.

```jsx
const Button = ({ text, children }) => {
  return (
    <button>
      {text}
      {children}
    </button>
  );
};
```

---

**6. Props를 사용하는 이유**

```text
UI 구조
→ 컴포넌트로 재사용

변경되는 데이터
→ Props로 전달
```

즉, 비슷한 컴포넌트를 여러 개 만드는 대신 하나의 컴포넌트에 다른 데이터를 전달해서 재사용한다.

---

**7. 핵심 정리**

* Props는 부모에서 자식으로 데이터를 전달한다.
* Props는 객체 형태로 전달된다.
* 구조 분해 할당으로 필요한 Props를 바로 받을 수 있다.
* 구조 분해 할당에서 기본값도 지정할 수 있다.
* `{...객체}`로 여러 Props를 한 번에 전달할 수 있다.
* 태그 사이의 내용은 `children`으로 전달된다.
* Props를 사용하면 같은 UI 구조를 재사용하면서 데이터만 다르게 표현할 수 있다.
