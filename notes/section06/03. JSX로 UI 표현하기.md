# Section 6 - 3. JSX로 UI 표현하기

**1. JSX란?**

JSX는 JavaScript 안에서 **HTML과 비슷한 형태로 UI를 작성하는 문법**이다.

```jsx
const Main = () => {
  return <div>메인</div>;
};
```

---

**2. JSX에서 JavaScript 사용**

JSX 안에서는 `{}`를 사용해 JavaScript 표현식을 넣을 수 있다.

```jsx
const name = "이정환";

return <div>{name}</div>;
```

다음처럼 계산이나 조건 표현식도 사용할 수 있다.

```jsx
<div>{1 + 2}</div>
<div>{user.name}</div>
<div>{user.isLogin ? "로그아웃" : "로그인"}</div>
```

`if`문은 JSX의 `{}` 안에 직접 작성할 수 없다.

---

**3. JSX 기본 규칙**

### a. 태그는 반드시 닫기

```jsx
<img />
<input />
<br />
```

### b. 최상위 요소는 하나

```jsx
return (
  <div>
    <div>첫 번째</div>
    <div>두 번째</div>
  </div>
);
```

불필요한 HTML 요소를 만들고 싶지 않다면 Fragment를 사용한다.

```jsx
return (
  <>
    <div>첫 번째</div>
    <div>두 번째</div>
  </>
);
```

---

**4. 조건부 렌더링**

조건에 따라 다른 UI를 보여주는 것을 조건부 렌더링이라고 한다.

### a. 삼항 연산자

```jsx
return (
  <>
    {user.isLogin ? <div>로그아웃</div> : <div>로그인</div>}
  </>
);
```

간단한 조건에 적합하다.

### b. if문

```jsx
if (user.isLogin) {
  return <div>로그아웃</div>;
}

return <div>로그인</div>;
```

조건에 따라 반환할 UI 자체를 나눌 때 사용할 수 있다.

---

**5. 스타일 적용**

### a. 인라인 스타일

React의 `style`에는 JavaScript 객체를 전달한다.

```jsx
<div
  style={{
    backgroundColor: "red",
    borderBottom: "5px solid green",
  }}
>
  로그아웃
</div>
```

CSS 속성 이름은 camelCase로 작성한다.

```text
background-color → backgroundColor
border-bottom    → borderBottom
```

### b. CSS 파일

```css
.logout {
  background-color: red;
  border-bottom: 5px solid green;
}
```

컴포넌트에서 불러온다.

```jsx
import "./Main.css";
```

JSX에서는 `class` 대신 `className`을 사용한다.

```jsx
<div className="logout">로그아웃</div>
```

---

**6. JSX에서 값 렌더링**

문자열이나 숫자는 바로 렌더링할 수 있다.

```jsx
<div>{name}</div>
<div>{10}</div>
```

객체 자체는 그대로 렌더링할 수 없으므로 필요한 프로퍼티를 사용한다.

```jsx
<div>{user.name}</div>
```

---

**7. 핵심 정리**

* JSX는 JavaScript 안에서 UI를 표현하는 문법이다.
* `{}` 안에서 JavaScript 표현식을 사용할 수 있다.
* JSX의 태그는 반드시 닫아야 한다.
* 여러 요소를 반환할 때는 하나의 부모 요소나 Fragment로 묶는다.
* 조건부 렌더링에는 삼항 연산자나 `if`문을 사용할 수 있다.
* 인라인 스타일은 `style={{}}` 형태로 작성한다.
* 인라인 CSS 속성은 camelCase를 사용한다.
* JSX에서는 `class` 대신 `className`을 사용한다.
* 객체 전체가 아니라 필요한 프로퍼티를 렌더링한다.
