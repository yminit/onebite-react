# Section 5 - 3. React App 구동 원리 살펴보기

**1. 개발 서버 실행**

Vite 프로젝트는 다음 명령어로 개발 서버를 실행한다.

```bash
npm run dev
```

`package.json`의 `scripts`에 있는 `vite` 명령어가 실행된다.

```json
{
  "scripts": {
    "dev": "vite"
  }
}
```

---

**2. localhost와 포트**

개발 서버는 보통 다음과 같은 주소에서 실행된다.

```text
http://localhost:5173
```

```text
localhost
→ 현재 내 컴퓨터

5173
→ 실행 중인 서버를 구분하는 포트 번호
```

---

**3. React App의 실행 구조**

Vite React 프로젝트의 핵심 연결 관계는 다음과 같다.

```text
index.html
→ main.jsx
→ App.jsx
→ 브라우저 화면
```

---

**4. index.html**

`index.html`에는 React App이 들어갈 `root` 요소가 있다.

```html
<div id="root"></div>
```

처음에는 비어 있고, React가 이 영역에 UI를 렌더링한다.

---

**5. main.jsx**

`main.jsx`는 React App을 시작하는 진입점 역할을 한다.

```jsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import App from "./App.jsx";

createRoot(document.getElementById("root")).render(
  <StrictMode>
    <App />
  </StrictMode>
);
```

핵심 흐름은 다음과 같다.

```text
#root 찾기
→ React Root 생성
→ <App /> 렌더링
```

---

**6. App.jsx**

`App.jsx`에는 실제 화면에 표시할 UI를 작성한다.

```jsx
function App() {
  return <h1>안녕 리액트</h1>;
}

export default App;
```

`App` 컴포넌트가 반환한 JSX가 화면에 표시된다.

---

**7. 전체 실행 흐름**

```text
npm run dev
→ Vite 개발 서버 실행
→ 브라우저에서 localhost 접속
→ index.html 로드
→ main.jsx 실행
→ #root에 React Root 생성
→ App 컴포넌트 렌더링
→ 브라우저 화면 표시
```

---

**8. 핵심 정리**

* `npm run dev`로 Vite 개발 서버를 실행한다.
* `localhost`는 현재 내 컴퓨터를 의미한다.
* 포트 번호는 실행 중인 서버를 구분한다.
* `index.html`에는 React가 사용할 `#root`가 있다.
* `main.jsx`는 React App을 시작하는 진입점이다.
* `App.jsx`는 실제 UI를 작성하는 컴포넌트이다.
* 전체 흐름은 `index.html → main.jsx → App.jsx → 화면`으로 이해하면 된다.
