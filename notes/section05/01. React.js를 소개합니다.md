# Section 5 - 1. React.js를 소개합니다

**1. React란?**

React는 Meta가 개발한 **오픈소스 JavaScript 라이브러리**이다.

UI를 컴포넌트 단위로 나누고, 상태 변화에 따라 화면을 효율적으로 업데이트할 수 있도록 도와준다.

---

**2. React의 핵심 특징**

React의 핵심은 크게 3가지이다.

```text id="react501"
컴포넌트 기반 UI
→ 화면을 작은 단위로 나눔

선언형 UI
→ 상태에 따라 어떤 화면을 보여줄지 작성

효율적인 업데이트
→ 필요한 부분만 실제 DOM에 반영
```

---

**3. 컴포넌트 기반 UI**

React에서는 화면을 여러 컴포넌트로 나누어 구성한다.

```text id="react502"
웹 페이지
├─ Header
├─ Main
├─ Button
└─ Footer
```

작은 UI 단위를 조합해 하나의 화면을 만들기 때문에 역할을 나누고 관리하기 쉽다.

---

**4. 선언형 화면 업데이트**

일반적인 명령형 방식은 DOM을 어떻게 변경할지 직접 처리한다.

```text id="react503"
요소 찾기
→ 값 계산
→ DOM 수정
```

React에서는 **상태에 따라 어떤 UI를 보여줄지** 작성한다.

```text id="react504"
상태 변경
→ React가 새로운 UI 계산
→ 화면 업데이트
```

즉, 개발자는 결과를 선언하고 실제 DOM 변경은 React가 처리한다.

---

**5. 브라우저의 화면 렌더링**

브라우저는 대략 다음 과정을 거쳐 화면을 표시한다.

```text id="react505"
DOM + CSSOM
→ Render Tree
→ Layout
→ Painting
→ 화면 표시
```

* `DOM`: HTML 구조 정보
* `CSSOM`: CSS 스타일 정보
* `Layout`: 요소의 크기와 위치 계산
* `Painting`: 실제 화면에 그리기

DOM 변경이 많으면 Layout과 Painting 같은 작업이 반복될 수 있다.

---

**6. Virtual DOM**

React는 화면 변경을 효율적으로 처리하기 위해 **Virtual DOM**을 사용한다.

```text id="react506"
상태 변경
→ 새로운 UI 계산
→ 이전 결과와 비교
→ 필요한 실제 DOM만 업데이트
```

개발자가 직접 DOM 변경 과정을 관리하지 않아도 React가 필요한 변경을 처리한다.

---

**7. 핵심 정리**

* React는 UI 개발을 위한 JavaScript 라이브러리이다.
* 화면을 컴포넌트 단위로 나누어 구성한다.
* 상태에 따라 UI를 정의하는 선언형 방식을 사용한다.
* 상태가 바뀌면 React가 새로운 UI를 계산한다.
* 브라우저는 DOM, CSSOM, Layout, Painting 과정을 거쳐 화면을 표시한다.
* React는 Virtual DOM을 이용해 필요한 실제 DOM 변경을 처리한다.
