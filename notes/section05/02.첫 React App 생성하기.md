# Section 5 - 2. 첫 React App 생성하기

**1. Vite로 React 프로젝트 만들기**

Vite를 사용하면 React 개발 환경이 준비된 프로젝트를 빠르게 만들 수 있다.

```bash
npm create vite@latest
```

생성 과정에서는 다음을 선택한다.

```text
Framework → React
Variant   → JavaScript
```

---

**2. 프로젝트 실행 준비**

생성한 프로젝트 폴더로 이동한다.

```bash
cd react-app
```

필요한 패키지를 설치한다.

```bash
npm install
```

또는

```bash
npm i
```

---

**3. 개발 서버 실행**

```bash
npm run dev
```

Vite 개발 서버가 실행되고 브라우저에서 React App을 확인할 수 있다.

개발 서버 종료:

```text
Ctrl + C
```

---

**4. 기본 프로젝트 구조**

```text
react-app/
├─ public/
├─ src/
├─ index.html
├─ package.json
└─ vite.config.js
```

주요 역할은 다음과 같다.

```text
src/
→ React 코드 작성

public/
→ 정적 파일 보관

index.html
→ 브라우저가 처음 불러오는 HTML

package.json
→ 프로젝트 및 패키지 정보

vite.config.js
→ Vite 설정
```

---

**5. 전체 흐름**

```text
npm create vite@latest
→ React 선택
→ JavaScript 선택
→ 프로젝트 폴더 이동
→ npm install
→ npm run dev
→ 브라우저에서 확인
```

---

**6. 핵심 정리**

* Vite로 React 프로젝트를 빠르게 생성할 수 있다.
* `npm create vite@latest`로 프로젝트를 만든다.
* 현재 학습에서는 `React + JavaScript`를 선택한다.
* `npm install`로 필요한 패키지를 설치한다.
* `npm run dev`로 개발 서버를 실행한다.
* React 코드는 주로 `src` 폴더에서 작성한다.
